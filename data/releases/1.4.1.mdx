# 1.4.1
##### December 18, 2025

## Web App
1. Fixed a bug with the graph component where it failed to render the data when all individual categories did not have the same data points. Now, if a category is missing data for a particular timestamp, it will show as zero for that timestamp instead of failing to render the graph altogether.
2. Added some more optimization to stop additional calls when changing graph parameters in the Infra Monitor tool.
3. Fixed minor bugs with some other admin tools with the View mode feature.
