# beta-0.33.4
##### July 12, 2024

## Snaps
### Inventory
- Released drop tables v2, which now supports inventory, currency, trackables XP and trackables energy drops. It also supports adding a complex drop table with min, max values and different weights.
- Drop tables and Containers now support escrow on rolls. This means that the item is not added to the inventory until the escrow is completed.

## Trackables Snap
- [Breaking] Renamed an API. The IncrementEnergy API has been changed to app auth only. The new way to consume energy will be using the ConsumeEnergy API.

## Web App
- Some UX improvements in the Snap configuration tools.
