# beta-0.52.3

##### July 10, 2025

## Snaps

### Auth
- Added documentation for the new `X` (formerly Twitter) connector. You can now use X to authenticate users in your app.
- Upgrading from Auth 0.52 to 0.52.3 was not working. This has been fixed and you can now upgrade your Auth Snap to 0.52.3 without any issues.

## Web App
- Fixed a bug where api-key SDK download was not working when you had a BYOSnap with a version less than 0.45.0.
- Added some Google SEO tags to the web app to improve search engine visibility.
