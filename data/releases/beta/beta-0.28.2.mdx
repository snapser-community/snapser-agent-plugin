# beta-0.28.2
##### April 17, 2024

## Enhancements
1. [Parties-Matchmaking]: We have rolled out an integration of the Parties Snap with the matchmaker. You can now queue up for matchmaking with your party and all be matched together.
2. [Inbox]: We have released a new Snap called Inbox. This Snap allows user to user as well as admin to user messages.
3. [Notifications]: The notifications snap has a new connector for sending Roblox notifications to users.
4. [Admin UX]: We have made some major changes to the Admin UX. With this change you will find it easier to navigate the admin tools.

## Bug Fixes
1. [Matchmaking]: The profile enable disable feature has been fixed.


## Documentation
1. Minor documentation update.
