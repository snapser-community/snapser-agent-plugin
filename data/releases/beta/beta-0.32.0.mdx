# beta-0.32.0
##### June 12, 2024

## Enhancements

1. [BYOSnap]: BYOSnap now supports multi-environment configuration.
2. [CLI]: The Snapctl tool now supports a multi-environment configuration input for the `byosnap publish-version` command.
3. [Auth]: Auth snaps email connector now supports custom email templates and sender email address setup.
4. [Notifications]: Notification snaps now supports custom sender email address setup. Templates and campaigns now support CSV imports. Additionally, push and email campaigns can now be setup for All users.
5. [Localized Notifications]: Notifications snap now supports multi-language templates.


## Bug Fixes
1. [Snapend Status]: Snapend status now reflects game services and fleet status.
2. [Heatmap]: Minor UX fix in the heatmap tool.


## Documentation
1. Minor updates to the Snapser documentation.
