# beta-0.52.2

##### July 09, 2025

## Snaps
### Inventory
- Added support for inventory discounts. You can now create discounts and then attach them to inventory items.

### Auth
- Added a new connector for `X` fka `Twitter`. You can now use X to authenticate users in your app.

## Web App
- Cost explorer now shows if you are using more snaps than the free snaps included in your tier.
- Added meta tags that shows a preview of Snapser, when someone shares the Snapser link on social media.
