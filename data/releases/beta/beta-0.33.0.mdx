# beta-0.33.0
##### July 10, 2024

## Features
-  **Geo Fleets**: Fleets now support multiple geos. With this release we are unlocking Sao Paulo and Frankfurt. You can now start a fleet in any of these locations. The fleet control plane will automatically allocate game servers in the selected geo.

## Web App
- **Logs**: Fixed an issue where older logs were not being retrieved in the Snapend logs tool.
- **UX**: The Infrastructure Monitor, Logs and Heatmap now have a consistent UX.
- **Live Ops Tool**: The Live Ops tool / Customer service tool has received a major UX upgrade.
- **BYOSnap Memory Slider**: Fixed the broken BYOSnap Memory slider in the BYOSnap details view.

## Snaps
- All snaps have been upgraded to 0.33.0. A core library update has been made to all the Snaps for picking
up configuration changes.

### Matchmaking Snap
- The matchmaker snap now supports the ability to match into a lobby.

## CLI Tool
- **Snapctl**: New generate command added for game studios wishing to upload their own BYO images to their Snapser ECR.

## Documentation
- Minor updates to the Snapser documentation.
