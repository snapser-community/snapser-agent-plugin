# 1.1.1
##### October 16, 2025

## Snaps

### Leaderboards
- Addition of **Reset** ability to a leaderboard. This will clear all entries in the leaderboard and create a fresh leaderboard.
- You can now edit leaderboards as long as the start time is 5 minutes in the future.


## Bug Fixes
### Quests
- Quests User Manager tool now properly displays the quest's current status.

### Web App
- Snapend tools are now accessible when the snapend is in `WARNING` state, in addition to `LIVE` state.
