# Inbox

The Inbox Snap allows developers to give every user their own message inbox. The Snap can be used to send
user to user or game/app admin to user messages. The Snap also supports sending messages to a group of users.

## Concept

The Inbox snap is mainly responsible for the following:

1. Sending user to user messages.
2. Sending user to friends messages.
3. Sending user to followers messages.
4. Sending user to guild/clan messages.
5. Sending admin to user messages.

## Message Type
Presently, this snap only supports text based messages.

## APIs

The `Inbox` snap exposes the following APIs

<div className="apisTable">
| API Name                  | HTTP Method | API Description                          |
| ------------------------- | ----------- | ---------------------------------------- |
| [InboxSendInboxFollowersMessage](#inboxsendinboxfollowersmessage-api) | POST        | Send a message to all followers          |
| [InboxSendInboxFriendsMessage](#inboxsendinboxfriendsmessage-api)   | POST        | Send a message to all friends            |
| [InboxSendInboxGuildMessage](#inboxsendinboxguildmessage-api)     | POST        | Send a message to all members of a guild |
| [InboxSendInboxUserMessage](#inboxsendinboxusermessage-api)      | POST        | Send a message to a user                 |
| [InboxDeleteMessagesByIds](#inboxdeletemessagesbyids-api)       | DELETE      | Delete message from a inbox              |
| [InboxGetMessages](#inboxgetmessages-api)               | GET         | Get messages from a inbox                |
| [InboxReadMessagesByIds](#inboxreadmessagesbyids-api)         | PUT         | Read messages from a inbox               |
| [InboxGetMessageById](#inboxgetmessagebyid-api)            | GET         | Get message from a inbox                 |
</div>
