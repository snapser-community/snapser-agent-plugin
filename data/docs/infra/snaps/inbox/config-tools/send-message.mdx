# Send Message
This tool allows a game studio to blast out messages to a group of users. You can select the segment of users you want to send the message to.

To get started:
1. Click on Send Message from the side Nav.
2. You will see a form where you can pick a segment, enter the message subject and content and send the message.

## Send Message Settings
- **Segment**: Select the segment of users you want to send the message to. You will need the Statistics and Segmentation snap to be snapped in to use this feature.
- **Subject**: The subject of the message. This can be any string. Max length is 100 characters.
- **Message**: The content of the message. Max length is 1000 characters.
