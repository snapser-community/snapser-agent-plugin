# Inbox Settings
You have the ability to control the following settings for each category:
- User Messages
- Guild/Clan Messages
- Friends Messages
- Followers Messages
- Segment Messages

To get started:
1. Click on Inbox Settings from the side Nav and select the category you want to configure.
2. You will see a form with the following fields that you can configure:

## Status
- **Enabled**: Toggle to enable or disable the category.

## Message Settings
- **Max Message Length**: Maximum length of messages that can be sent.
- **Message Retention Days**: Number of days the inbox message needs to be retained.
- **Daily Send Limit**: Maximum number of messages that can be sent by a user in a day.
- **Receiver Message Limit**: Maximum number of messages that a receiver can receive in a day. This prevents spamming.
- **Max Inbox Size**: Maximum number of messages that can be stored in the inbox.
