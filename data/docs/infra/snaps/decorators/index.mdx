# Decorators

The Snapser Decorators service enhances API responses by automatically injecting user-specific metadata — such as attributes from the **Profiles** or **Statistics** snaps — into the results of supported APIs. This allows clients to avoid chaining multiple API calls to fetch profile or stat data for users referenced in leaderboard entries, friends lists, lobbies, and more.

<Warning>
  Decorators is a Premium snap. You will need to be on a Premium plan to use it.
</Warning>

## Why Use Decorators?

When fetching data like leaderboard scores, friends, or lobbies, it's common to also need user attributes like `gamer_tag`, `country`, or `wins`. Normally, you'd fetch that data separately. With Decorators, Snapser will automatically enrich your response with that metadata — server-side.

<Note>
This improves client performance and reduces both API call count and response latency.
</Note>

## Supported APIs

Currently, the following Snapser APIs can be decorated:

| API Path | Request Type |
| -------- | ------------- |
| `/guilds.GuildsService/GetGuild` | `guilds.GetGuildRequest` |
| `/guilds.GuildsService/GetGuildForUserId` | `guilds.GetGuildForUserIdRequest` |
| `/leaderboards.LeaderboardsService/GetScores` | `leaderboards.GetScoresRequest` |
| `/lobbies.LobbiesService/GetLobby` | `lobbies.GetLobbyRequest` |
| `/parties.PartiesService/GetParty` | `parties.GetPartyRequest` |
| `/social_graph.SocialGraphService/GetFriends` | `social_graph.GetFriendsRequest` |
| `/social_graph.SocialGraphService/GetFollows` | `social_graph.GetFollowsRequest` |
| `/social_graph.SocialGraphService/GetFriendRequests` | `social_graph.GetFriendRequestsRequest` |

## Making a Request

To use decorators, make a call to the `Decorators` snap and include:

- `rpc`: the full RPC path of the Snapser API you want to decorate.
- `request`: a base64-encoded payload of the original request message.
- `decorators`: an object specifying which attributes to pull from `profiles` and/or `statistics`.

### Example Request Payload

```json
{
  "decorators": {
    "statistics": [
      "wins"
    ],
    "profiles": [
      "gamer_tag"
    ]
  },
  "rpc": "/leaderboards.LeaderboardsService/GetScores",
  "request": "CgZnbG9iYWwSJDMzYTk5MWNkLTBhZTctNDkxNy1hZjA5LWQ1NjM3MmRkYWM2ZRoDdG9wIAooADAA"
}
```
In this example:
- The rpc points to the GetScores leaderboard API.
- The request is a base64-encoded protobuf message.
- Snapser will decorate each user in the response with gamer_tag (from Profiles) and wins (from Statistics).
