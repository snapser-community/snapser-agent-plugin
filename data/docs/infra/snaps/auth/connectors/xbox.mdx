# XBox Login

Click here to view all Auth Snap [connectors](/docs/infra/snaps/auth/connectors).

## Overview

Xbox Login is a connector that allows users to log into your application using their XBox Live account.
This connector leverages the XBox Live SDK to ensure a smooth and secure login experience.

## Setup Requirements
### Step 1: Create an Xbox Developer Account
- Apply for the ID@Xbox Program: Go to the [ID@Xbox website](https://www.xbox.com/en-US/developers/id) and apply for the ID@Xbox program. This is required for publishing games on Xbox.
- Alternatively, you can use the Xbox Live Creators Program for UWP games, but this has limitations compared to ID@Xbox.

### Step 2: Create an Xbox App:
- Once accepted into the ID@Xbox program, create an Xbox app in the [Microsoft Partner Center](https://partner.microsoft.com/en-us/dashboard). This will provide you with necessary IDs for integration.

## How it works

To implement XBox Login, game studios must configure the connector via the Auth Configuration, Connector tool.
Details on setting this up are available below in the "Configuration Tool" section.

After configuration, the studio should integrate the XBox SDK for the relevant platform into the game client.
The SDK, upon successful authentication, returns a token which should then be sent to the backend server.
The Auth Snap receives this token, verifies its authenticity with Unreal's servers, and if valid, issues a
user ID and session token back to the game client. This enables user authentication within the game.

Let's dive into both these steps in detail below.

## Integrating the XBox SDK

### Unity Integration
1. Use the GDK and GDK Unity Plugins: For ID@Xbox, use the Game Development Kit (GDK) and its Unity plugins. You can find more information on the GDK at [https://aka.ms/gdk](https://aka.ms/gdk).
    <Note>
        The Xbox Live Unity Plugin is no longer actively developed, so use the GDK plugins instead.
    </Note>
2. Implement Xbox Live Sign-in feature: The GDK Unity package includes example scenes for sign-in etc. You can use these examples to understand how to access Xbox services. The sign-in example uses a prefab (**GdkHelper**) that automatically signs in to Xbox services when the scene is run.

### Unreal Integration
1. Get Access to Xbox One Development Tools: If accepted into the ID@Xbox program, contact Epic Games to gain access to the Unreal Engine build that supports Xbox One development. This build includes tools for integrating Xbox Live features.
2. Use Xbox Live Integration: Unreal Engine uses the Online Subsystem for Xbox Live integration. You can enable the Xbox Live module in your project settings. The **IOnlineIdentity** interface handles account-related interactions, including authentication.
```cpp
#include "CoreMinimal.h"
#include "GameFramework/PlayerController.h"
#include "OnlineSubsystem.h"
#include "OnlineSubsystemSteam.h"

class AMyPlayerController : public APlayerController
{
public:
    void BeginPlay() override
    {
        Super::BeginPlay();

        // Initialize the Xbox Online Subsystem
        IOnlineSubsystem* OnlineSubsystem = IOnlineSubsystem::Get();
        if (OnlineSubsystem)
        {
            IOnlineIdentity* IdentityInterface = OnlineSubsystem->GetIdentityInterface();
            if (IdentityInterface)
            {
                // Attempt to log in
                FOnlineAccountCredentials Credentials;
                IdentityInterface->Login(0, Credentials, FOnLoginCompleteDelegate::CreateLambda([](int32 LocalUserNum, bool bWasSuccessful, const FUniqueNetIdRepl& UserId, const FString& ErrorStr) {
                                             if (bWasSuccessful)
                                             {
                                                 UE_LOG(LogTemp, Log, TEXT("Xbox Live login successful"));
                                             }
                                             else
                                             {
                                                 UE_LOG(LogTemp, Error, TEXT("Xbox Live login failed: %s"), *ErrorStr);
                                             }
                                         }));
            }
        }
    }
};
```

## Usage

Game studios have the option to start user sessions with an Anonymous login and later upgrade to a secure
XBox login, or they can begin directly with an XBox login. If opting for the latter, simply store and
utilize the user ID and session token returned by the Auth Snap to interact with other APIs on your Snapend.
For upgrading from an Anonymous to an XBox login, follow the example below.

### Example

1. Assume a game client initiates an AnonLogin request using the device's unique identifier as the username.
2. The Auth Snap generates a new user profile with `user_id=395d9b91-72fd-40f2-a3cd-cf5a1e7a604f` and `session_token=9a052312-48f6-4710-a072-230ddd046a2d`.
3. The game client prompts the user to secure their account via XBox Login, displaying the UI recommended by Microsoft.
4. The client integrates with the XBox SDK to authenticate the user and receives a **token**.
5. Next, the client submits an **XBoxLogin** request with the **token** and sets **create_user=true**.
6. The client receives a new **user_id** and **session_token** linked to the XBox Live account.
7. To merge these accounts, the client utilizes the **AssociateLogins** API, specifying which account to retain and which to discard.
8. The Auth Snap finalizes the association, discarding the unwanted user ID and token, preserving the necessary ones.

This procedure ensures the account remains secure, as access cannot be gained merely through knowing the username used in the AnonLogin API.
