# Epic Login

Click here to view all Auth Snap [connectors](/docs/infra/snaps/auth/connectors).

## Overview

Epic Login is a connector that allows users to log into your application using their Epic Games account.
This connector leverages the Epic Online Services SDK to ensure a smooth and secure login experience.

## Setup Requirements
### Step 1: Set Up Epic Games Store Account
- Create Developer Account: Create a developer account on the Epic Games Developer portal.
- Onboarding Process: Follow the onboarding steps provided by Epic Games to set up your account and access publishing tools.

## How it works

To implement Epic Login, developers must configure the connector via the Auth Configuration, Connector tool.
Details on setting this up are available below in the "Configuration Tool" section.

After configuration, the studio should integrate the Epic Online Services SDK for the appropriate platform into the app client.
The SDK, upon successful authentication, returns a token which should then be sent to the backend server.
The Auth Snap receives this token, verifies its authenticity with Unreal's servers, and if valid, issues a
user ID and session token back to the app client. This enables user authentication within the game or app.

Let's dive into both these steps in detail below.

## Configuration Tool
The Epic Connector configuration tool needs the following details:

### Credentials
Please open up your Epic Developer portal to get your app client Id and secret
1. <u>Client Id</u> - Your unique app client identifier
2. <u>Client Secret</u> - Your game or app's secret

## Integrating the Epic Online Services SDK
Epic Login is part of Epic Online Services. You will need to integrate EOS into your game to use Epic Login.

### Download the EOS SDK
- Visit the [Epic Games Developer Portal](https://dev.epicgames.com/portal/.): Go to [dev.epicgames.com](https://dev.epicgames.com) and log in with your Epic Games account.
- Access the SDK Page: Once logged in, navigate to the SDK section. You can find the latest SDKs for different platforms, including PC (C or C#), Android, iOS, PlayStation, Xbox, and Nintendo Switch.
- Download the SDK: Choose the appropriate SDK for your platform and follow the instructions to download it.
- Implement Login Flow: Implement the login flow using the EOS SDK. This typically involves initializing the EOS client, handling user authentication, and managing sessions

#### Unity and Unreal Engine Integration
There are plugins available that simplify the integration process:
1. Unity Plugin: The PlayEveryWare [EOS Plugin](https://github.com/PlayEveryWare/eos_plugin_for_unity) for Unity is available on GitHub and can be installed via the Unity Package Manager (UPM)8.
2. Unreal Engine OSS: The EOS Online Subsystem (OSS) plugin is integrated directly into Unreal Engine, starting from version 4.27
		- a. Enable the OSS EOS Plugin in Unreal Engine
			-	Open Unreal Engine Editor: Launch your Unreal Engine project.
			- Enable the Plugin: Navigate to Edit > Plugins and enable the Online Subsystem EOS plugin. This will also enable related plugins like EOS Plus and EOS Shared by default9.
			- Restart the Editor: After enabling the plugins, restart the Unreal Engine editor to apply the changes.
		- b. Configure the OSS EOS Plugin
			- Edit DefaultEngine.ini: Open the DefaultEngine.ini file located in your project's Config directory.
			- Set Default Services: Add or modify the following lines to set EOS as the default platform service:
			```text
			[OnlineServices]
			DefaultServices=Epic
			```
			- Configure Network Drivers: Add the necessary network driver configurations to support EOS. Refer to Unreal Engine documentation for specific settings

## Usage

Developers have the option to start user sessions with an Anonymous login and later upgrade to a secure
Epic login, or they can begin directly with an Epic login. If opting for the latter, simply store and
utilize the user ID and session token returned by the Auth Snap to interact with other APIs on your Snapend.
For upgrading from an Anonymous to an Epic login, follow the example below.

### Example

1. Assume a game client initiates an AnonLogin request using the device's unique identifier as the username.
2. The Auth Snap generates a new user profile with `user_id=395d9b91-72fd-40f2-a3cd-cf5a1e7a604f` and `session_token=9a052312-48f6-4710-a072-230ddd046a2d`.
3. The game client prompts the user to secure their account via Epic Game Services Login, displaying the UI recommended by Epic Games.
4. The client integrates with the Epic Online Services SDK to authenticate the user and receives a **token**.
5. Next, the client submits an **EpicLogin** request with the **token** and sets **create_user=true**.
6. The client receives a new **user_id** and **session_token** linked to the Epic Online Services account.
7. To merge these accounts, the client utilizes the **AssociateLogins** API, specifying which account to retain and which to discard.
8. The Auth Snap finalizes the association, discarding the unwanted user ID and token, preserving the necessary ones.

This procedure ensures the account remains secure, as access cannot be gained merely through knowing the username used in the AnonLogin API.
