# Google Login

Click here to view all Auth Snap [connectors](/docs/infra/snaps/auth/connectors).

## Overview

Google Login is a connector that allows users to log into your application using their Google ID.
This connector leverages the Sign in with Google API to ensure a smooth and secure login experience.

## Setup Requirements
### Step 1: Create a Google Cloud Project:
- Go to the [Google Cloud Console](https://console.cloud.google.com/) and create a new project.
- Enable the Google Sign-In API for your project.

## How it works

To implement Google Login, developers must configure the connector via the Auth Configuration, Connector tool.
Details on setting this up are available below in the "Configuration Tool" section.

After configuration, the studio should integrate the Google SDK (Engine based or Firebase SDK) for the appropriate platform into the app client.
The SDK, upon successful authentication, returns a token which should then be sent to the backend server. The
Auth Snap receives this token, verifies its authenticity with Google's servers, and if valid, issues a user
ID and session token back to the app client. This enables user authentication within the app.

Let's dive into both these steps in detail below.

## Configuration Tool
The Google Connector configuration tool needs the following details:

### Credentials
Please open up your Google / Android Developer portal to get your app's client Id and secret
1. <u>Client Id</u> - Your unique app client identifier
2. <u>Client Secret</u> - Your game's or app's secret

## Integrating the Google SDK
Google provides a SDK for Unity however there isn't one for Unreal Engine.

### Unity Integration
1. Download the Google Sign-In SDK for Unity: Visit the [GitHub repository](https://github.com/googlesamples/google-signin-unity) to download the Google Sign-In SDK for Unity.
2. Import the SDK into your Unity project using the **Unity Package Manager** or by importing the **.unitypackage** file.
3. Configure the SDK: Open the sample scene provided with the SDK and enter your Web Client ID in the SignInSampleScript component. Ensure you have configured a web client ID in the Google Cloud Console for your project.
4. Implement Google Login: Use the SDK to implement the login flow. You can use the sample scripts provided to handle user authentication.
```csharp
using GoogleSignIn;

public class GoogleSignInExample : MonoBehaviour
{
    public void Login()
    {
        GoogleSignIn.Configuration = new GoogleSignInConfiguration("YOUR_WEB_CLIENT_ID");
        GoogleSignIn.DefaultInstance.SignIn();
    }
}
```
#### Firebase Integration (Optional):
1. Create a Firebase project and enable Google Sign-In in the Firebase console.
2. Import the Firebase Auth SDK into your Unity project.
3. Follow Firebase's documentation for integrating Google Sign-In with Unity using Firebase.

### Unreal Engine Integration
Unfortunately, there isn't a native Google Sign-In SDK for Unreal Engine like there is for Unity. However, you can manually implement Google authentication using Google's REST API or by integrating a third-party plugin.

1. Manual Implementation: Use Google's REST API to handle authentication manually. This involves creating a login flow where users are redirected to Google for authentication and then return to your app with an access token.
2. Third-Party Plugins: Look for community-created plugins that integrate Google authentication into Unreal Engine.

## Usage

Developers have the option to start user sessions with an Anonymous login and later upgrade to a secure
Google login, or they can begin directly with an Google login. If opting for the latter, simply store and
utilize the user ID and session token returned by the Auth Snap to interact with other APIs on your Snapend.
For upgrading from an Anonymous to an Google login, follow the example below.

### Example

1. Assume a game client initiates an AnonLogin request using the device's unique identifier as the username.
2. The Auth Snap generates a new user profile with `user_id=395d9b91-72fd-40f2-a3cd-cf5a1e7a604f` and `session_token=9a052312-48f6-4710-a072-230ddd046a2d`.
3. The game client prompts the user to secure their account via Google Login, displaying the UI recommended by Google.
4. The client interacts with the Firebase SDK to authenticate the user and receives a **token**.
5. Next, the client submits an **GoogleLogin** request with the **token** and sets **create_user=true**.
6. The client receives a new **user_id** and **session_token** linked to the Google account.
7. To merge these accounts, the client utilizes the **AssociateLogins** API, specifying which account to retain and which to discard.
8. The Auth Snap finalizes the association, discarding the unwanted user ID and token, preserving the necessary ones.

This procedure ensures the account remains secure, as access cannot be gained merely through knowing the username used in the AnonLogin API.
