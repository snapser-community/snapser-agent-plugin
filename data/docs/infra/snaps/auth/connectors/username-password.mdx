# Username Password Login

Click here to view all Auth Snap [connectors](/docs/infra/snaps/auth/connectors).

## Overview

This traditional email-password authentication method allows users to log in using a user defined username and a password. The username has to be unique across the Snapend.

## How it works

To implement Username Password Login, developers must configure the connector via the Auth Configuration, Connector tool. Details on setting this up are available below in the "Configuration Tool" section.

1. The app client can use the **VerifyUsername** API to check if the username is available.
1. The app client initiates an **UsernamePasswordLogin** request using the username and password.
1. The Auth snap issues a user ID and session token back to the app client.
6. The client can now use the user ID and session token to interact with other APIs on the Snapend.

## Usage

Developers have the option to start user sessions with an Anonymous login and later upgrade to a secure Username password login, or they can begin directly with an Username password login. If opting for the latter, simply store and utilize the user ID and session token returned by the Auth Snap to interact with other APIs on your Snapend.
For upgrading from an Anonymous to an Username Password login, follow the example below.

### Example

1. A game client initiates an AnonLogin request using the device's unique identifier as the username.
1. The Auth Snap generates a new user with `user_id=395d9b91-72fd-40f2-a3cd-cf5a1e7a604f` and `session_token=9a052312-48f6-4710-a072-230ddd046a2d`.
1. The client displays a prompt for the user to secure their account by entering a username and a password.
1. The client makes a request to the **UsernamePasswordLogin** API and gets a **user_id** and **session_token** for the account.
7. To merge these accounts, the client uses the **AssociateLogins** API, specifying which credentials to retain or discard.
8. The Auth Snap then consolidates the accounts based on these preferences.

## Configuration Tool

To enable Email Password authentication, select **Username Password** from the connector menu, which will show you a dialog with a form. Snapser needs the following details to activate your connector.

### Password settings
1. <u>Regex Pattern</u>: The pattern that the password should match. This is a regex pattern that will be used to validate the password. For example, if you want to enforce a minimum length of 8 characters, you can use the regex pattern `^(?=.{8,})`. You can also use other regex patterns to enforce other rules like special characters, numbers, etc.
