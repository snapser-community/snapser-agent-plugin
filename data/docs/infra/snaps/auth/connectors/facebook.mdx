# Facebook Login

Click here to view all Auth Snap [connectors](/docs/infra/snaps/auth/connectors).

## Overview

Facebook Login is a connector that allows users to log into your application using their Meta / Facebook credentials.
This connector leverages the [Facebook Login API](https://developers.facebook.com/docs/facebook-login/) to ensure a smooth and secure login experience.

## Setup Requirements
### Step 1: Create a Facebook Developer Account
- Go to the [Facebook developer portal](https://developers.facebook.com/) and create an account if you don't have one.
- Create a new Facebook app and note the App ID and Client Token.

## How it works

To implement Facebook Login, developers must configure the connector via the Auth Configuration, Connector tool. Details on setting this up are available below in the "Configuration Tool" section.

After configuration, the studio should integrate the Facebook SDK for the relevant platform into the app client. The Facebook SDK, upon successful authentication, returns a token which should then be sent to the backend server. The Auth Snap receives this token, verifies its authenticity with Facebook's servers, and if valid, issues a user ID and session token back to the app client. This enables user authentication within the app.

Let's dive into both these steps in detail below.

## Configuration Tool
The Facebook connect configuration tool needs the following details:

### Credentials
Please open up your Facebook Developer portal to get your app's client Id and secret
1. <u>Client Id</u> - Your unique app client identifier
2. <u>Client Secret</u> - Your game's or app's secret

## Integration with Facebook Authentication APIs
Facebook provides a SDK for Unity however there isn't one for Unreal Engine.

### Unity Integration
1. Download the Facebook SDK for Unity: Visit the Facebook Developer portal to download the latest Facebook SDK for Unity.
2. Import the SDK into your Unity project using `Assets > Import Package > Custom Package...`.
3. Configure Facebook Settings in Unity:
	- Open the Unity Editor and go to Facebook > Edit Settings.
	- Enter your Facebook App ID and Client Token.
4. Implement Facebook Login: Use the Facebook SDK to implement login functionality. You can use the
	**FB.LogInWithReadPermissions** method to request permissions like public_profile and email.
```csharp
using Facebook.Unity;

public class FacebookExampleScript : MonoBehaviour
{
    public void Login()
    {
        var perms = new List<string>() { "public_profile", "email" };
        FB.LogInWithReadPermissions(perms, result =>
                                           {
                                               if (FB.IsLoggedIn)
                                               {
                                                   // Handle successful login
                                               }
                                               else
                                               {
                                                   // Handle login failure
                                               }
                                           });
    }
}
```

### Unreal Engine Integration
Unfortunately, there isn't a native Facebook SDK for Unreal Engine like there is for Unity. However, you can integrate Facebook authentication using third-party plugins or by manually implementing Facebook's REST API for authentication.

1. Use Third-Party Plugins: Look for community-created plugins that integrate Facebook authentication into Unreal Engine.
2. Manual Implementation: Use Facebook's REST API to handle authentication manually. This involves creating a login flow where users are redirected to Facebook for authentication and then return to your app with an access token

## Usage

Developers have the option to start user sessions with an Anonymous login and later upgrade to a secure Facebook login, or they can begin directly with an Facebook login. If opting for the latter, simply store and utilize the user ID and session token returned by the Auth Snap to interact with other APIs on your Snapend. For upgrading from an Anonymous to an Facebook login, follow the example below.

### Example

1. Assume a game client initiates an AnonLogin request using the device's unique identifier as the username.
2. The Auth Snap generates a new user profile with `user_id=395d9b91-72fd-40f2-a3cd-cf5a1e7a604f` and `session_token=9a052312-48f6-4710-a072-230ddd046a2d`.
3. The game client prompts the user to secure their account via Facebook Login, displaying the UI recommended by Meta.
4. The client interacts with the Facebook SDK to authenticate the user and receives a **token**.
5. Next, the client submits an **FacebookLogin** request with the **token** and sets **create_user=true**.
6. The client receives a new **user_id** and **session_token** linked to the Facebook account.
7. To merge these accounts, the client utilizes the **AssociateLogins** API, specifying which account to retain and which to discard.
8. The Auth Snap finalizes the association, discarding the unwanted user ID and token, preserving the necessary ones.

This procedure ensures the account remains secure, as access cannot be gained merely through knowing the username used in the AnonLogin API.
