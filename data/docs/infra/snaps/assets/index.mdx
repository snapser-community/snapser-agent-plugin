# Assets

The **Assets Snap** allows you to upload app/game and user-generated assets to Snapser's backend and view them through a Content Delivery Network (CDN). This service provides an easy and efficient way to manage assets, while ensuring that they are securely stored and delivered.

<Warning>
  This is presently a Premium snap. We plan to soon make it available on all plans. If you want early access, please reach out to us on Discord.
</Warning>

## Buckets
The Assets Snap uses buckets to organize assets. A bucket is a container that holds assets. Each bucket has a unique name and can be of type **User** or **App**.
1. **User Buckets**: User buckets are meant to store assets that are user generated.
2. **App Buckets**: App buckets are meant for storing app assets, uploaded by the developer, that can be pulled by all the game/app clients.

Each upload takes in the following parameters:
1. **Bucket Name**: The name of the bucket where the asset will be stored.
2. **File Path**: The path inside the bucket where the asset will be stored.
3. **Filename Override**: The name of the file to be stored.
4. **Obfuscate Filename**: Whether to obfuscate the filename.
5. **Replace**: Whether to replace the existing asset with the same name.
6. **Visibility**: The visibility of the asset. For App assets the visibility is always public.

<Note>
	**IMPORTANT**: Deleting a bucket will result in the deletion of all assets stored in the bucket. Please exercise caution when deleting buckets.
</Note>

### Bucket Name
The bucket name is a unique identifier for the bucket. The bucket name should be created before uploading assets to the bucket. You can do this using the Snap Configuration Tool.

<Note>
	Snapser creates a bucket called **user** of type **User** by default. This bucket is used to store user-generated assets.
</Note>

### File Path
The file path is the path inside the bucket where the asset will be stored. The file path is completely upto the developer to decide how they want to organize their assets.

#### Example
If you have a bucket named **user-crafting-uploads** and you want to store a assets stored by the user according to the arena they are in, you can use the following file path:
```text
user-crafting-uploads/arena-1
```

### Filename Override
The filename override is the name of the file to be stored. If the filename override is not provided, the original name of the file will be used.

### Obfuscate Filename
The obfuscate filename parameter is used to obfuscate the filename. When the filename is obfuscated, the filename is replaced with a random string. This is useful when you want to prevent users from figuring out the paths and mine the assets.

<Note>
	This is a soft security measure that you can take advantage of.
</Note>

### Replace
The replace parameter is used to replace the existing asset with the same name. If the replace parameter is set to true, the existing asset will be replaced with the new asset. If the replace parameter is set to false, the upload will fail if an asset with the same name already exists.

### Visibility
The visibility parameter is used to set the visibility of the asset. The visibility can be set to public or private. If the visibility is set to public, the asset can be accessed by anyone. If the visibility is set to private, the asset can only be accessed by the caller who uploaded the asset.

For, App assets the visibility is always public.

## Automating App Asset Uploads
You can automate the process of uploading assets to the Assets Snaps > App bucket using the Snapser Server SDK. The SDK provides a an **UploadAsset** API that you can use.

<Note>
	You will need the Auth Snap and a API Key to use the SDK.
</Note>

## APIs

The `Assets` snap exposes the following APIs

<div className="apisTable">
| API Name              | HTTP Method | API Description                        |
| --------------------- | ----------- | -------------------------------------- |
| [AssetsDeleteAppAssets](#assetsdeleteappassets-api) | DELETE        | Delete app assets                |
| [AssetsDeleteAssets](#assetsdeleteassets-api)        | DELETE        | Delete assets for a user                 |
| [AssetsGetAppAssets](#assetsgetappassets-api)         | GET         | Get app assets |
| [AssetsGetAssets](#assetsgetassets-api)         | GET         | Get assets for a user |
| [AssetsUploadAppAsset](#assetsuploadappasset-api)       | POST        | Upload app asset                |
| [AssetsUploadAsset](#assetsuploadasset-api)       | POST        | Upload asset for a user                |
</div>
