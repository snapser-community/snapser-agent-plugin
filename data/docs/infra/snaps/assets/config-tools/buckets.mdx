# Buckets
This tool is used to create and manage buckets. You can create a new bucket by clicking on the **Add Bucket** button.

## Bucket Details
1. **Bucket Name**: The name of the bucket.

## Bucket Type
1. **User**: User buckets are meant to store assets that are user generated.
1. **App**: App buckets are meant for storing game assets, uploaded by the game studio, that can be pulled by all the game clients.

## Allowlisted Extensions
The Assets snap allows you to specify which file extensions are allowed for upload. Only the file types in the
allowlist will be accepted for uploading.

<Note>
	App buckets are not restricted by the allowlisted extensions. Whereas User buckets need at least one
	extension.
</Note>

## Max File Size
Each uploaded asset has a file size limit. If an asset exceeds the specified size limit, the upload will be
rejected. This prevents excessively large files from overloading the system.
