# App Assets
This tool is used to view and manage app assets. You can view all the assets uploaded to the app buckets
here. You can also upload or delete assets from this tool.

## Bucket Selector
You can select the bucket from the dropdown to upload assets to.

## File Details
The file path is the path inside the bucket where the asset will be stored. The file path is completely
upto the game studio to decide how they want to organize their assets.

## Attach File
You can attach a file to upload to the selected bucket.

## Bucket Visibility
The visibility parameter is used to set the visibility of the asset. The visibility can be set to public or
private. If the visibility is set to public, the asset can be accessed by anyone. If the visibility is set to
private, the asset can only be accessed by the caller who uploaded the asset. For, App assets the visibility
is always public.

## Asset Replace
A toggle to replace the existing asset with the same name. If the toggle is on, the existing asset will be
replaced with the new asset. If the toggle is off, the upload will fail if an asset with the same name already
exists.
