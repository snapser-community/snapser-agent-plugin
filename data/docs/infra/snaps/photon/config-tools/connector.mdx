# Photon Connector Settings
This tool provides a callback URL and a client secret key that you need to set up on the Photon dashboard.

To get started:
1. Click on `Connector` from the side navigation.
2. You will see a form exposing all the details you need for this integration.

## Callback URL
1. **Callback URL**: This is the URL that Photon will use to verify the session token. This URL is generated by Snapser and is unique to your Snapser account.

## Client Secret
1. **Client Secret**: This is the secret key that you need to set up on the Photon dashboard. This key is generated by Snapser and is unique to your Snapser account.
