# User Chat
This tool allows you to set up rules and restrictions for user-to-user chat in your game.
Using this tool. you can enable or disable chat, set the maximum message length, and configure the
message retention period. Additionally, you will find settings that help you prevent chat harassment.

To get started:
1. Click on User Chat from the side Nav.
2. This will show you a form, where you can update your User chat settings.

![Admin Settings Pic](/images/docs/chat-admin-settings.png)

## User Chat Status
- <u>Enable Chat</u> - Enable or disable chat for users.

## User Chat Message Settings
- <u>Max Message Length</u> - Set the maximum length of a chat message.
- <u>Message Retention</u> - Enable message retention and set the number of days to retain messages. You can retain messages for up to 28 days.

## User Chat Harassment Prevention
- <u>Require Chat Acceptance</u> - Require users to explicitly accept chat messages from other users. If this setting is enabled, users will not receive chat messages from other users unless they have accepted messages from them.

<Note>
We highly recommend enabling the **Require Chat Acceptance** setting to prevent spam and harassment in your app.
</Note>
