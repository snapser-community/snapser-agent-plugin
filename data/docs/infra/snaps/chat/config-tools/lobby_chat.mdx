# Lobby Chat
This tool allows you to set up rules and restrictions for lobbies chat in your game or app.
Using this tool, you can enable or disable lobbies chat, set the maximum message length, and configure the message retention period.
You need the Lobbies Snap to be snapped in to use this tool.

To get started:
1. Click on Lobbies Chat from the side Nav.
2. This will show you a form, where you can update your Lobby Chat settings.


## Lobby Chat Status
- <u>Enable Lobbies Chat</u> - Enable or disable lobby chat for users.

## Lobby Chat Message Settings
- <u>Max Message Length</u> - Set the maximum length of a chat message.
- <u>Message Retention</u> - Enable message retention and set the number of days to retain messages. You can retain messages for up to 28 days.
