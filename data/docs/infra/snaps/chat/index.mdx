# Chat

The Chat snap enables players in a game or app to communicate with each other in real time.

## Chat Types

The Chat snap currently supports the following types:

1. **User to User Chat**: Allows users to send 1-on-1 messages to other users.
2. **Guild Chat**: Allows users within a guild to participate in a common chat room. Messages are delivered to all the members of the guild.
the members of the party.
3. **Lobby Chat**: Allows users within a lobby to participate in a common chat room. Messages are delivered to all the
members of the lobby.

## Transport

If you enable [Websocket](/docs/infra/snaps/hermes) in your Snapend gateway, messages will be delivered to the users in real time over their websocket session. This is the recommended way to use Chat.
Without Websocket, you can still receive messages by polling the API to get messages between two users or for a guild. These APIs support passing in `from` and `to` parameters
that enable polling by only returning messages that were send within that time frame.

Note that this can only work if you have enabled message retention in the snap settings.

### Web socket integration

It is recommended to use Chat with Websocket. Doing so enables true real-time communication between your players. The overall flow is as follows -

#### Direct Messages over Websocket

1. **User A** and **User B** connect to Websocket over websocket connections.
2. **User A** sends a message to Websocket of the type `chat_direct_message_send` specifying the `target_user_id` of User B and the message `content`.
3. **User B** receives a message from Websocket of the type `chat_direct_message_received` with the message `content` and the User ID of the `sender` in real time.

#### Guild Chat over Websocket

1. **User A**, **User B**, and **User C** are three members of **Guild X** that connect to Websocket over websocket connections.
2. **User A** and **User B** send a message to Websocket of the type `chat_guild_room_join` specifying the `guild_id` of **Guild X** to join its chat room. **User C**
does not join the guild chat room.
3. **User A** sends a message to Websocket of the type `chat_guild_message_send` specifying the `guild_id` of **Guild X** and the message `content`.
4. **User B** receives a message from Websocket of the type `chat_guild_message_received` with the message `content`, along with the `guild_id` and the User ID of the `sender`.
**User C** does not receive the message, since they did not join the guild chat room.


## Chat History

You can enable message retention in the Snap admin tool for both direct message chat and for guild chat. After doing this, the chat snap will
start keeping track of any new messages that are sent. You can configure the number of days for which messages are retained, for a maximum of
up to 28 days. You can get these messages by calling the appropriate APIs. You can pass in UNIX timestamps to the `from` and `to` parameters of
these APIs to avoid fetching the entire message history.


## Avoiding Spam

You can configure Chat snap to require users to explicitly accept chat messages from other users, by turning on the **Require Chat Acceptance** setting in the Direct Message
admin tool. After enabling this, Websocket will not send the `content` of message from users to the target user, if they have not accepted messages from them. Websocket will still notify
the target user that someone is trying to send them chat messages by sending a message of the type `chat_unaccepted_direct_message_received` with the User ID of the sender.

Users can also block other users if they no longer want to receive messages from them. Accepting or blocking direct messages for users can be done by calling the `SetPermission` API.

## APIs

The `Chat` snap exposes the following APIs

<div className="apisTable">
| API Name           | HTTP Method | API Description                                   |
| ------------------ | ----------- | ------------------------------------------------- |
| [ChatJoinRoom](#chatjoinroom-api)           | POST        | Join a room chat                                  |
| [ChatLeaveRoom](#chatleaveroom-api)          | POST        | Leave a room chat                                 |
| [ChatGetRoomMessages](#chatgetroommessages-api)    | GET         | Get messages from a room chat                     |
| [ChatSendRoomMessage](#chatsendroommessage-api)    | POST        | Send a message to the room                        |
| [ChatGetConversations](#chatgetconversations-api)   | GET         | Get user conversations                            |
| [ChatGetDirectMessages](#chatgetdirectmessages-api)  | GET         | Get direct messages from a chat with another user |
| [ChatSendDirectMessage](#chatsenddirectmessage-api)  | POST        | Send a direct message to another user             |
| [ChatGetUserPermissions](#chatgetuserpermissions-api) | GET         | Get the list permissions set for a user           |
| [ChatSetUserPermission](#chatsetuserpermission-api)  | POST        | Set chat permissions for a user and target user   |
</div>
