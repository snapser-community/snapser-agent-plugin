# Social Graph

Most games or social apps rely heavily on social aspects to drive engagement and retention.
User relationships within a game in particular are a key pillar of the social experience.
However, managing these relationships can be a complex task. The Social Graph
snap completely handles the management of user relationships, allowing you to
focus on building the best social experience for your game.

## Supported Relationships

The Social graph snap supports the following relationship types:

1. **Friends**: A mutual relationship between two users. Both users have to accept the friend request for the relationship to be established.
2. **Followers**: A one-way relationship between two users. The user who is being followed does not have to accept the follow request for the relationship to be established.
3. **Blocks**: A one-way relationship between two users. The user who is being blocked does not have to accept the block request for the relationship to be established.

## Concept

Two concepts are key to understanding how the Social graph snap manages user
relationships viz. Objects and Associations.

### Objects

Objects are entities that have associations to each other. They have one or
more associations and those associations may also have a bilateral sister
association. Objects represent a repeatable pillar of data, for example, a
user. Each object can have JSON metadata attached to it, which can be used to
record extra information about the object such as a "nickname" or the
"birth date" of a user.

### Associations

These are the actions that objects take on other objects, for example,
following, sending a friend request, or blocking. Associations often come in
pairs to provide bidirectional relationships that can be easily queried from
both objects. For example a User can “follow” another user; and that other
user was “followed by” the first user. Each association can have JSON metadata
attached to it, which can be used to record extra information about the
association such as a "friendship level", or the "reason" for a block.

#### Association Depth

Presently, you are able to view friends of friends.

## Friend Codes

Friend codes are a way to establish a relationship between two users via a
mechanism that does not require the users to be friends on the platform where
the game is hosted. Friend codes are also easy to share and can be used to establish a relationship
between two users quickly.

The social graph snap supports the following friend codes:
1. Digit code
2. Alphanumeric code
3. Alphabetic code

These codes need to be 5-9 characters long.

<Note>
When the user enters the friend code, the social graph snap will establish a
"friend request" relationship between the two users. The target user
will have to accept the friend request for the relationship to be established.
</Note>

## User Presence

If the snapend is configured with websockets, the Social Graph snap will automatically propagate user presence 
information to the friends of a user. On websocket connection, the snap will send a message to all friends of 
the user indicating that the user is online. When the websocket connection is closed, the snap will send a message 
to all friends of the user indicating that the user is offline.

Users can also send presence updates to via the `Message_UserPresenceRequest` websocket message. This can be used to 
set a current status message, toggle do-not-disturb, or to indicate that the user is currently playing a game. This 
information will be propagated to all other guild members of the user.

## APIs

The `Social Graph` snap exposes the following APIs

<div className="apisTable">
| API Name            | HTTP Method | API Description                                                                                    |
| ------------------- | ----------- | -------------------------------------------------------------------------------------------------- |
| [SocialGraphisConnected](#socialgraphisconnected-api)   | GET        | Checks if a user is connected to the target user                                      |
| [SocialGraphFriendCode](#socialgraphfriendcode-api)          | POST        | Returns the user's friend code, creates one if it doesn't exist                                    |
| [SocialGraphUpdateUserMetadata](#socialgraphupdateusermetadata-api)  | PUT         | Updates a user object's metadata                                                                   |
| [SocialGraphGetBlockedUsers](#socialgraphgetblockedusers-api)     | GET         | Returns users blocked by the user                                                                  |
| [SocialGraphBlock](#socialgraphblock-api)               | POST        | Creates a block association with the target user                                                   |
| [SocialGraphUnblock](#socialgraphunblock-api)             | DELETE      | Removes a block association with the target user if it exists                                      |
| [SocialGraphGetFollows](#socialgraphgetfollows-api)          | GET         | Returns user objects that are followers of the user or the user objects that the user is following |
| [SocialGraphFollow](#socialgraphfollow-api)              | POST        | Creates a follow association with the target user                                                  |
| [SocialGraphUnfollow](#socialgraphunfollow-api)            | DELETE      | Removes a follow association with the target user if it exists                                     |
| [SocialGraphGetFriendRequests](#socialgraphgetfriendrequests-api)   | GET         | Returns friend requests sent or received by the user                                               |
| [SocialGraphSendFriendRequest](#socialgraphsendfriendrequest-api)   | POST        | Creates a sent_friend_request association with the target user                                     |
| [SocialGraphDeleteFriendRequest](#socialgraphdeletefriendrequest-api) | DELETE      | Removes a friend request that was sent to or received from the target user if it exists            |
| [SocialGraphGetFriends](#socialgraphgetfriends-api)          | GET         | Returns friends of the user                                                                        |
| [SocialGraphAddFriend](#socialgraphaddfriend-api)           | POST        | Creates a friend association with the target user                                                  |
| [SocialGraphRemoveFriend](#socialgraphremovefriend-api)        | DELETE      | Removes a friend association with the target user if it exists                                     |
| [SocialGraphGetUserSettings](#socialgraphgetusersettings-api)     | GET         | Returns the user's settings                                                                        |
| [SocialGraphUpdateUserSettings](#socialgraphupdateusersettings-api)  | PUT         | Sets the user's settings                                                                           |
| [SocialGraphGetFriendsCount](#socialgraphgetfriendscount-api) | GET | Returns the count of friends for a user |
| [SocialGraphGetFollowsCount](#socialgraphgetfollowscount-api) | GET | Returns the count of followers or following for a user |
