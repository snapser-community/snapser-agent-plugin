# Social Graph Settings
This tool allows you to add or disable `friend` relationship based settings

To get started:
1. Click on `Settings` from the side Nav.
2. You will then see a form where you can add or update your settings.

## Friends Configuration
These are the settings that you can configure for the `friend` relationship.

### Friends can view friends
1. **Toggle**: Enabling this allow users to view the friends of their friends.

### Friend Code Configuration
1. **Toggle**: Enabling this allows users to establish a relationship between two users via a friend code.
  - **Type**: Select the type of friend code you want to use. You can chose between `Numeric`, `Alphanumeric`, or `Alphabetic`.
  - **Length**: Select the length of the friend code. You can chose a number between `5` to `8`.

### Friends Count
1. **Toggle**: A public or private toggle setting. Making friends count public allows other users to see how many friends a user has. By default, this is set to private.

## Follow Configuration
These are the settings that you can configure for the `follow` relationship.

### Followers and Following Count
1. **Toggle**: A public or private toggle setting. Making these counts public allows other users to see how many followers and followings a user has. By default, this is set to private.

## Block Configuration
These are the settings that you can configure for the `block` relationship.

### Remove Associations On Block
1. **Toggle**: Enabling this updates the social graph behavior to remove existing associations between users if one of them blocks the other.
