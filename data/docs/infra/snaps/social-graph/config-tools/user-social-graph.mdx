# User Social Graph
This tool allows you to view all the data in the social graph for a given user by specifying their User ID.

To get started:
1. Click on `User Tools > User Social Graph` from the side Nav.
2. You will then see a form where you can enter the User ID of the user you want to view the social graph for.

## User Social Graph Details
This tool allows you to view the social graph for a particular user. You can see the user’s friends, followers, and blocked users.

1. **User ID**: Enter the User ID of the user to view their social graph.
