# Block User
This tool allows you to block a user on behalf of another user.

To get started:
1. Click on `User Tools > Block` from the side Nav.
2. You will then see a form where you can block a user on behalf of another user.

## Block User Details
1. **Target ID**: Enter the User ID of the user you want to block.
2. **User ID**: Enter the User ID of the user who is blocking the other user.
