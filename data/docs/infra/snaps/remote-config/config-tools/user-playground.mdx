# User Playground Tools
## 1. Playground Override Tool
This tool allows you to preview the configuration that would be returned when you select one or more overrides.

### Playground Override Selector
1. **Overrides**: Select one or more overrides to preview the resulting configuration.

### Playground Override Preview
1. **Final User Configuration**: The resulting configuration after applying the selected overrides.

## 2. Playground User Tool
This tool allows you to preview the configuration that would be returned for a given user.

### Playground User
1. **User Id**: Enter the user ID for whom you want to preview the configuration.
