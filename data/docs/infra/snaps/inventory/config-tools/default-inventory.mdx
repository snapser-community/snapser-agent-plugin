# User Tools Default Inventory

This tool allows you to set the default inventory items and currencies for a user.
You can also set the inventory items and currencies to start from zero.

To get started:
1. Click on `User Tools > Default Inventory` from the side Nav.
2. You will then see a form where you can set the default inventory items and currencies for a user.

## Default Inventory Details
- **Items**: The default inventory items and or containers for the user.
- **Currency**: The default inventory currencies for the user.

<Note>
  Note only non-stackable inventory items can have a default quantity of 0. For
  stackable items the value has to be greater than 0.
</Note>
