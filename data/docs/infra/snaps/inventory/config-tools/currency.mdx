# Currency Tools

## 1. Inventory Currency
This tool allows you to create, update, and delete virtual currencies. You can also view all the currencies in the catalog.

To get started:
1. Click on Currency > Currencies from the side Nav.
2. Click on the Add a Currency button.

### Currency Details
- **Name**: The name of the currency. This should be an alphanumeric string.
- **Display Name**: The display name of the currency. This will be the user facing name of the currency.

![Admin Currency](/images/docs/inventory-currency.png)

## 2. Inventory Currency Exchange
This tool allows you to define the exchange rates between your virtual currencies.

To get started:
1. Click on `Currency > Currency Exchange` from the side Nav.
2. Click on the `Add a currency conversion` button.

### Currency Exchange Currencies
- **Source Currency**: The currency you want to convert from.
- **Target Currency**: The currency you want to convert to.

### Currency Exchange Rate
- **Rate**: The conversion rate between the two currencies. Maximum of two decimal places are supported.

Example: Say you want to convert 1 gem to 100 coins. You would set source currency as gems, target currency as coins and rate as 100.

![Admin Currency Conversion](/images/docs/inventory-currency-conversion.png)
