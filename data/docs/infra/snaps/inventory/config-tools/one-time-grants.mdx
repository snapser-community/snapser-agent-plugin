# One Time Grants

This tool allows you to create, update, and view one time grants that can be applied once to users and at the same time added incrementally over time.

## One Time Grant Details

- **Name**: The name of the grant. This should be an alphanumeric string.
- **Grant Id**: The grant id for the grant. This will be the naming in which the grant will be identified.
- **Description**: An optional description of the one time grant.
- **Active**: This toggle indicates whether the grant is active or not. You can switch the status anytime.

## One Time Grant Rewards

One time grants support **Items, Currencies, Drop Tables, Xp and Energy** rewards. Each grant must have at least one reward.
