# Inventory Import
This tool allows you to import catalog items and containers from a CSV file.

To get started:
1. Click on Inventory > Import from the side Nav.
2. Click on the Import button > From CSV File.
3. This will open up a form where you can upload your Inventory CSV.

## Field Descriptions
1. name - The unique name of the item. This is a required field and should be alphanumeric without spaces.
2. display_name - The display name of the item. This is the name that will be shown to the users.
3. class_name - The class name of the item. This is used to group similar items together.
4. description - The description of the item.
5. stackable - Whether the item is stackable or not. This is a boolean field with values TRUE or FALSE.
6. tradable - Whether the item is tradable or not. This is a boolean field with values TRUE or FALSE. (Presently, not really used, but will be in future releases)
7. ttl - The time to live of the item in seconds. 0 means the item never expires. A non-zero value means the item will expire after that many seconds from the time it is added to the inventory.
8. consumable - Whether the item is consumable or not. This is a JSON field with the following structure: `{"is_consumable": true}`. Leave it empty if the item is not consumable.
9. container - Whether the item is a container or not. This is a JSON field with the following structure: `{"items": {"item_name": quantity}, "virtual_currencies": {"currency_name": amount}, "drop_tables": {"drop_table_name": weight}, "unlock_cost": [{"type": "ENERGY|ITEM|CURRENCY", "name": "name", "count": amount}]}`. Leave it empty if the item is not a container.
10. purchasable - Whether the item is purchasable or not. This is a JSON field with the following structure: `{"settings": [{"price": $amount, "currency": "$currency_name", "display_price": $display_amount}]}`. Leave it as `"{""settings"":[]}"` if the item is not purchasable.
11. sub_inventory - Whether the item is a sub-inventory or not. This is a JSON field with the following structure: `{"is_sub_inventory": true}`.
12. user_inventory_instance_limit - The maximum number of instances of this item that a user can have in their inventory. This is an integer field. Use 0 for unlimited instances.
13. user_inventory_instance_limit_per_sub_inventory - The maximum number of instances of this item that a user can have within a single sub-inventory. This is an integer field. Use 0 for unlimited instances. This limit is checked per-scope: when granting to a sub-inventory, only items in that sub-inventory count against the limit.
14. metadata - The metadata of the item. This is a JSON field where you can add any additional information about the item.
15. tags - The tags of the item. This is a comma separated list of strings.

<Warning>
  IMPORTANT: The `user_inventory_instance_limit` field is only supported in Inventory 1.4.0 and above. If you are using an older version of the Inventory snap, please do not include this field in your CSV.
</Warning>

<Warning>
  IMPORTANT: The `user_inventory_instance_limit_per_sub_inventory` field is only supported in Inventory 1.6.0 and above. If you are using an older version of the Inventory snap, please do not include this field in your CSV.
</Warning>

<Note>
  The example below needs you to add a currency called `gold` in your virtual currencies before you import the CSV.
</Note>
