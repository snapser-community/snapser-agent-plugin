# Guilds

The Guilds snap provides games or social apps with the ability to create user clans or groups. Many games/apps allow users to team up as part of a guild or a clan. These user groups can then be incentivized to work towards a common goal, or to compete amongst
themselves as a community. Each guild has an "admin" who is responsible for managing guild metadata and memberships.

## Guild Types

The Guilds snap supports the following guild types:

1. **Public**: As the name suggests, any user can choose to join these type of guilds at any time, as long as they still have available slots.
2. **Private**: Users cannot join private guilds directly. They have to request membership to private guilds, which are visible to the guild admin. The guild admin can then decide to add them to the guild, or to reject their request.

<Note>A user can only be a part of a single guild at any given time.</Note>

## Custom metadata

Each guild has a **metadata** property that can store an arbitrary JSON object. The guild admin is allowed to update the **metadata** of the guild. Further, each guild member also has a **metadata** JSON object that can be updated by the member themselves.

## Guild admins

Each guild has a single member who is designated as the guild admin. By default, the creator of the guild is made the admin for that guild.

### Any user can

- Join public guilds
- Request to join private guilds
- Update the member metadata for themselves within a guild
- Participate in the guild and inter-guild leaderboards
- Leave their current guild

### But only guild admins can

- Add members to the guild
- Remove / kick members from the guild
- Accept or reject membership requests for private guilds
- Update the guild metadata
- Make the guild **public** or **private**
- Transfer admin privileges to a different member of the guild
- Delete the guild

<Note>
  Since each guild should always have an admin, admin members cannot leave the
  guild until they transfer the admin privileges to some other guild member.
</Note>

## Guild Leaderboards
The Guilds snap integrates with the Leaderboards snap. This allows you to unlock an inter guild leaderboard with almost no setup.

<Note>
  Guild leaderboards are completely optional. But you essentially get them for free without any additional setup.
</Note>

### Inter-guild

If your game or app also uses the **Leaderboards** snap, you can enable **Inter-guild Leaderboard** in the Guilds snap. Enabling this option will create a common leaderboard that all guilds can be a part of. Any guild members can contribute to and increment the score for their guild on this leaderboard. You can enable this option, and configure the
behavior of this leaderboard through the `Leaderboard Configuration Tool` for the Guilds snap.

## User Presence

If the snapend is configured with websockets, the Guilds snap will automatically propagate user presence information to members of the same guild. On websocket connection, the snap will send a message to all other guild members of
the user indicating that the user is online. When the websocket connection is closed, the snap will send a message to all other guild members of the user indicating that the user is offline.

Users can also send presence updates to via the `Message_UserPresenceRequest` websocket message. This can be used to set a current status message, toggle do-not-disturb, or to indicate that the user is currently playing a game. This information will be propagated to all other guild members of the user.
