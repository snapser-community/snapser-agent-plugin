# Blob Manager
This tool allows you to manage the blobs you have setup in your game. You can view, update, and delete the blobs from this tool.

To get started:
1. Click on `Blobs Manager` from the side Nav.
2. You will see a form where you can enter the detail of the blob you are trying to
	 manage.

## Category
1. **Type** - The type of blob. This can be a blob, append blob, counter or json blob.

## Access
1. **Type** - The access type of the blob. This can be public, protected, or private.

## Inputs
1. **Blob Name** - The name of the blob you are trying to manage.
1. **Owner ID** - The owner ID of the blob. This is the user ID of the user who owns the blob.
1. **JSON path** (optional) - For blobs of type JSON, you can enter the JSON path of the blob you are trying to manage.
<Note>
	The JSON path is only applicable if you are trying to manage a JSON blob.
</Note>
