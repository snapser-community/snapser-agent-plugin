# Snaps Overview

Snapser's suite of pre-built backend features aka **Snaps** encompasses a wide array of functionalities to fulfill all your application or game needs.

## Snaps

- [Analytics](/docs/infra/snaps/analytics) - Offers customizable event setup and seamless data querying via an admin tool, supporting batch event uploads and providing exposed APIs for integration, making it essential for optimizing app performance and user experience.
- [Auth](/docs/infra/snaps/auth) - Offers easy integration of authentication into apps/games, supporting anonymous, email, and third-party authentication like Steam, Xbox, Facebook, Apple, and Google.
- [Chat](/docs/infra/snaps/chat) - Enables real-time communication with Direct Messages and Guild/Group Chats. Users receive messages instantly, with customizable retention settings for message history.
- [Client Logs](/docs/infra/snaps/client-logs) - Helps client developers debug issues exclusive to devices, enabling effective issue logging and tracking.
- [Events](/docs/infra/snaps/events) - Enables developers to schedule and execute events within their apps, facilitating milestone-based actions like push notification blasts, remote config overrides, and quest management for enhanced user engagement.
- [Experiments](/docs/infra/snaps/experiments) - Facilitates A/B testing in apps, enabling developers to run concurrent experiments for specific user segments, schedule tests, and create control and treatment variants to assess new features and content effectively.
- [Game Server Fleets](/docs/infra/snaps/game-server-fleets) - For multiplayer game use cases, this snap manages global server fleets for scalable and reliable game server solutions, supporting server scaling based on demand and offering multiple regions for deployment.
- [GDPR - CCPA](/docs/infra/snaps/gdpr) - Facilitate adherence to data privacy regulations like GDPR and CCPA, enabling users to access and delete their data via APIs, regardless of their location.
- [Guilds](/docs/infra/snaps/guilds) - Facilitates user group creation in apps/games, supporting public/private guilds or groups. Admins manage memberships and data, while Leaderboards track scores for inter-guild competitions.
- [In-app purchases](/docs/infra/snaps/iap) - Validates purchase receipts from Google Play and Apple App Store, and can automatically grant items upon successful transactions.
- [Inventory](/docs/infra/snaps/inventory) - Facilitates catalog item setup, currency configuration, and drop table creation, streamlining player inventory and currency wallet management.
- [Leaderboards](/docs/infra/snaps/leaderboards) - Enables easy integration of competitive elements into games, supporting both global and tiered leaderboards. It offers flexibility with recurring and non-recurring leaderboards and provides admin tools for setup and management.
- [Matchmaking](/docs/infra/snaps/matchmaking) - Pairs users based on customizable rules, integrating seamlessly with other services like Leaderboards. It simplifies grouping with Tickets, Match Profiles, and Rules, supporting various rule types for flexibility. Integration with Stratos/Titan ensures matches across regions, while latency rules optimize allocation.
- [Notifications](/docs/infra/snaps/notifications) - Enables sending push notifications and emails to users, supporting bulk messaging, targeted campaigns, and dynamic content through templates.
- [Parties](/docs/infra/snaps/parties) - Enables apps/games to create temporary user groups with public or private visibility. Party owners manage membership and settings, while users can join public parties.
- [Profile - User](/docs/infra/snaps/profiles) - Simplifies user profile management for apps/games, offering customizable attributes and access control.
- [Quests](/docs/infra/snaps/quests) - Allows for the integration of quests or missions into apps or gamifieid apps, with tasks that need to be completed to finish the quest. Quests can be recurring or one-time and offer rewards upon completion. Tasks can track inventory items, currency, or statistics. Setup involves defining quest details, tasks, and rewards via the Quest admin tool.
- [Remote Config](/docs/infra/snaps/remote-config) - Provides dynamic app configurations with low latency, supporting base configurations and overrides for tailored user experiences. Developers can schedule, monitor, and validate overrides, accessing version history for changes. Additionally, a Playground tool allows previewing configuration effects.
- [Relay](/docs/infra/snaps/relay) - Provides a global relay network for real-time multiplayer games, ensuring low latency and high availability. It supports multiple regions, automatic allocation, and latency-based matchmaking, streamlining game development and enhancing user experience.
- [Scheduler](/docs/infra/snaps/scheduler) - Allows scheduling HTTP actions based on Cron or one-time events. Integrated with Snaps like Experiments and Notifications, it simplifies task scheduling and monitoring through the Admin Tool.
- [Sequencer](/docs/infra/snaps/sequencer) - Streamlines app development by chaining multiple API calls into sequences, simplifying complex actions with just one API call. It supports up to 10 API calls per sequence, enables variable usage across calls, and offers enhanced error handling by stopping execution on the first failure.
- [Social Graph](/docs/infra/snaps/social-graph) - Streamlines user relationship management in games or social apps, handling friend connections, followers, and blocks.
- [Statistics and Segmentation](/docs/infra/snaps/statistics) - Enables real-time user statistics and segmentation for customized player experiences, facilitating easy setup and integration via admin tools and APIs.
- [Storage](/docs/infra/snaps/storage) - Provides cloud storage for app data, supporting various blob types and access levels. It ensures scalability, redundancy, and concurrency control, simplifying integration and usage for developers.
- [Trackables](/docs/infra/snaps/trackables) - Facilitates progression tracking, XP level management, and energy setup, streamlining game or gamifieid app development with customizable scopes and automatic level assignment based on XP scores.

## Access
### APIs via SDKs
All Snaps can be accessed via RESTful APIs. Snapser generates a custom SDK for each Snapend, which can be used to interact
with the Snaps. The SDKs are available in multiple languages like C++, C#, Go, Java, Python, Node.js etc.

Your Custom code and Game Servers can also talk to your Snaps via HTTP or gRPC using special **App** or
**Internal** SDKs. Check out the [SDKs](/docs/snapend/sdks) documentation to learn more.

All SDKs obey the rules of the Snapend Network Harness. The harness is a secure network that allows low
latency and high throughput network connectivity between all the building blocks of your Snapend.
Check out the [Intra Snapend Networking](/docs/snapend/networking/intra-snapend) documentation to learn more.

### Websocket
In addition, Snapser provides a highly scalable Web socket server called Hermes for your Snapend. Allowing
you to establish a single connection to your backend and invoke APIs exposed by Snaps in your Snapend.
Check out the [Websocket](/docs/infra/snaps/hermes) documentation to learn more about how Snapser enables full-duplex communication between clients and backend,
allowing for real-time experiences. Also if you add the Eventbus Snap to your Snapend, you can listen
to events broadcasted by Snaps in your Snapend, thus giving you a way to react to changes in your game or app state.
