# Parties

The Parties snap provides games with the ability to create ephemeral user groups. These groups are

## Party Types

The Party snap supports the following party visibility types:

1. **Public**: As the name suggests, any user can choose to join these type of parties at any time, as long as they still have available slots.
2. **Private**: Users cannot join private parties directly. They have to request membership to private parties, which are visible to the party owner. The party owner can then decide to add them to the party, or to reject their request.

## Ownership and Permissions

Party owners are the users who created the party. They have the ability to update the party, approve or reject membership requests, and delete the party.

If a party owner leaves the party, party ownership is transferred to another party member.

### Any user can

- Join public parties
- Search for public parties
- Leave their party

### But only party owners can

- Approve requests to join the party
- Ban / kick / un-ban members from the party
- Update the party configuration and meta
- Delete the party

## Party Metadata

Each Party has a **metadata** property that can
store an arbitrary JSON object. The party owner is allowed to update the **metadata** of the party.

Further, each party member also has a **metadata** JSON object that can be defined when the player joins the party.

## Tools

The [Parties tool](/docs/snapend/tools/parties) lets you search parties on a Snapend and manage their
players, invites, join requests and bans from the web portal.

## Snaps Integration

Parties snap is integrated with the following snaps:

### Matchmaking

Parties Snap is now integrated with the Matchmaking Snap. Users can queue up for matchmaking as a party (`matchmaking.CreateTicketsForParty`) and ensure that
all party members are matched into the same game. Additionally, we've improved the Parties integration with our websocket
gateway to emit several new events about the lifecycle of a Party and its players.

#### Latency Rules

If a matchmaking profile wants to use a Latency Rule as well as Party matchmaking, then the player latencies must be added to the player's metadata when they join the party. 
Then, when `matchmaking.CreateTicketsForParty` is called, the correct latencies will be used for each player in the party. Optionally, the party owner can also set a 
default latency for the party, which will be used if a player does not have a latency set in their metadata.

<Note>
  The Parties Snap is a work in progress. We are working on adding more
  integrations like chat, social graph, and voice.
</Note>

### Websocket Events emitted by snap

When [Web sockets](/docs/infra/snaps/hermes) are enabled on your snapends gateway, this snap can broadcast specific events related to statistics changes directly to the game clients.
These events are targeted to the appropriate user. Each event is uniquely identified by an enum, and the event payload is a well-structured protobuf message.
These protobuf messages can be downloaded from the Downloads page.

| Event Id | Event Name    | Description                            | Payload Message   |
| -------- | ------------- | -------------------------------------- | ----------------- |
| 1        | PARTY_JOINED  | Published when a user joins the party  | EventPartyJoined  |
| 2        | PARTY_LEFT    | Published when a user leaves the party | EventPartyLeft    |
| 3        | PARTY_DELETED | Published when a party is deleted      | EventPartyDeleted |
| 4        | PARTY_PLAYER_METADATA_UPDATED | Party member metadata updated       | EventPartyPlayerMetadataUpdated |
| 5        | PARTY_UPDATED | Party has been updated       | EventPartyUpdated |
| 6        | PARTY_USER_INVITED | Party user invite sent       | EventPartyUserInvited |
| 7        | PARTY_INVITE_ACCEPTED | Party invite has been accepted       | EventPartyInviteAccepted |
| 8        | PARTY_INVITE_DECLINED | Party invite has been declined       | EventPartyInviteDeclined |
| 9        | PARTY_MEMBER_KICKED   | Party member has been kicked         | EventPartyMemberKicked   |
| 10       | PARTY_CREATED | Party has been created       | EventPartyCreated |
