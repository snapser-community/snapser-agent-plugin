# Bundles
The tool allows you to create bundles that can be granted to users based on their purchases. You can
create a bundle by selecting items and containers from the Inventory Snap.

To get started:
1. Click on Bundles from the side Nav.
2. You can then click on Add a bundle to add a new bundle.

## Bundle Details
- **Name**: The name of the bundle. This should be an alphanumeric string.
<Note>
The bundle names you enter in this tool should match the bundle name in the store.
</Note>

## Grants
- **Type**: This will be an item or a currency.
- **Id**: The id of the item or currency.
- **Quantity**: The quantity of the item or currency.
<Note>
At least one grant is required for a bundle. A grant can be an item or a currency.
</Note>
