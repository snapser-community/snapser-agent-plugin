# User Transactions
The tool allows you to view all the transactions that have been made by the users. You can see the
status of the transaction and the items that were granted to the user.

To get started:
1. Click on Transactions from the side Nav.
2. You will see a text box where you can enter a user Id.
3. Click on the "View" button to see the transactions for that user.

## User Transactions
- **User Id**: The user id for which you want to see the transactions.
