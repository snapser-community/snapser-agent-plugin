# Cortex AI Backend Assistant

<Warning>
  Cortex is in alpha and we are rolling it out slowly to our community. If you would like to try it out, please join our Discord and ask for access.
</Warning>

**Snapser Cortex** is a homegrown AI backend assistant that helps you **build, manage, and maintain your Snapends**.

Cortex currently supports the following capabilities:

1. Creating Snapends
2. Updating Snapends
3. Downloading Custom SDKs
4. Diagnosing Snapends
5. Searching Docs
6. Scanning Repositories *(pre-alpha)*
7. Route to Snapend Tools

<Note>
 💡 **Ongoing Improvements**
 We’re actively adding new capabilities to Cortex. Check back often for updates or reach out on Discord with specific use cases you’d like supported.
</Note>

## 🛠️ Create Snapends

Cortex helps you generate the ideal backend configuration for your game or app. Describe what you’re building (or specify a genre), and Cortex will recommend the best Snapend layout.

You’ll receive a plan to review and approve. Once confirmed, Cortex will create your Snapend and offer a downloadable SDK to get started right away.


## 🔄 Update Snapends

Need to evolve your backend? Just describe the change or feature you'd like to add. Cortex will suggest the appropriate Snap(s) and generate a plan for your approval.

Once approved, Cortex will update the Snapend and provide an updated SDK.


## 📦 Download Custom SDKs

Cortex can generate and deliver a tailored SDK for any existing Snapend. Simply specify which Snapend you want the SDK for, and Cortex will give you a zipped package.


## 🩺 Diagnose Snapends

If your Snapend shows a red or orange dot (indicating an issue), Cortex can diagnose the problem for you. It will generate a report and offer recommended steps to resolve the issue.


## 📚 Search Docs

Ask Cortex any Snapser-related question. It will search the documentation and return a helpful answer—saving you time and clicks.


## 🔍 Scan Repositories *(Pre-Alpha)*

Cortex can analyze your code repository to suggest the best Snapend configuration.

For TypeScript projects, it also generates an integration file that connects seamlessly with the Snapser SDK—so you can start integrating immediately.

> 🧪 **Experimental Feature**
> This is still in pre-alpha. Feedback is appreciated—join our Discord and let us know what you think.

## 🛠️ Route to Snapend Tools
Cortex can help you find the right tools for managing your Snapends. Just ask it to route you to the appropriate Snapend tool, and it will automatically take you to the tool.


## 🚀 How to Access Cortex

- **Standard and Premium** plans: Cortex is available via the main navigation.
- **Starter** plan: A button will appear on the landing page to launch Cortex.
