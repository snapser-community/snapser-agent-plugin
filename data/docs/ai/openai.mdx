# OpenAI Integration

## Snapser Documentation Assistant (Custom GPT)

Snapser now has its own **Custom GPT** built on top of OpenAI’s ChatGPT platform — the **Snapser Documentation Assistant**.
This assistant gives you instant, conversational access to Snapser’s complete documentation and API reference directly inside ChatGPT.

Whether you’re exploring Snaps, setting up your first Snapend, or looking for an API example, the assistant uses the same indexed data that powers our in-app documentation search.

## What the Assistant Can Do

- ✅ Answer setup and integration questions about Snaps, Snapends, and Snapser APIs
- ✅ Retrieve examples and code snippets from our documentation
- ✅ Link you directly to relevant sections on [snapser.com/docs](https://snapser.com/docs)
- ✅ Provide context-specific guidance (Auth, Inventory, Leaderboards, etc.)

It’s like having the Snapser docs team right inside your ChatGPT window.


## How to Enable and Use It

1. **Open ChatGPT**
   Go to [https://chat.openai.com](https://chat.openai.com) and sign in with a Plus or Pro account (Custom GPTs require GPT-4 access).

2. **Open the Snapser GPT**
   Visit the public GPT link:
   👉 **[Launch Snapser Documentation Assistant](https://chatgpt.com/g/g-690e73f5569481918c8b705c3720fbd2-snapser-documentation-assistant)**

3. **Click “Use GPT”**
   This pins the SnapserGPT to your sidebar for quick access later.

4. **Ask Naturally**
   Try questions like:
   - “How do I configure a Snapend for multiplayer?”
   - “Show me an example of the Inventory Snap API request.”
   - “What are Leaderboards and how do they reset each season?”

The assistant will automatically retrieve the most relevant content from Snapser’s documentation and summarize it for you, with direct links back to the docs.


## Notes and Privacy

- The assistant does **not** access your Snapser projects or private data — it only uses public documentation hosted on [snapser.com/docs](https://snapser.com/docs).
- All responses are generated in real-time using OpenAI’s model and Snapser’s indexed knowledge base.
- For best results, phrase your questions as you would to a human (“How do I…?” or “What’s the difference between…?”).
