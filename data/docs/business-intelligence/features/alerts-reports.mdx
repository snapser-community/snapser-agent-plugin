# Alerts and Reports

Snapser allows you to enter a threshold query for a metric and get notified when the metric crosses that threshold.
You can setup an alert as follows:

1. **Condition** - The condition you want to set for the alert. Here you will have to write a SQL query
   that will return a single value for the database you are querying. Additionally, you can give an
   alert condition and value.
2. **Schedule** - You can set the schedule for the alert. You can set it to run every hour, day, week,
   month or on a cron schedule.
3. **Message Content** - You can set the message content for the alert. This can either be your
   dashboard or a chart.
4. **Notification Method** - You can set an email to get notified.
