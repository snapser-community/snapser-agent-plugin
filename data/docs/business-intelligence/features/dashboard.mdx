# Dashboard

Olympus Dashboards are a collection of charts. After creating your charts,
Olympus offers you a nice and clean way to visualize all your data visualization tools
and display them in an organized dashboard.

## How it works?

To add a Dashboard go to the Dashboard tab and click "Create Dashboard". You will
be taken to the Dashboard creation page. Here you can drag and drop charts from
the right hand side nav onto the main canvas. Olympus also allows you to resize
your dashboard within the canvas. You can add multiple charts and organize them
the way you want.

Olympus also offers additional layout elements to enhance your dashboard, like
headers, text labels, dividers, etc.

Once you are happy with it, give your Dashboard a name and save it. You can also
download your dashboards or send them via link.

![Olympus Dashboard](/images/docs/olympus-dashboard.png)

<Note>
  Snapser provides default graphs that have pre-baked charts for Business,
  Engagement and Session metrics.
</Note>

## Dashboards for Experiments

For each experiment you create using the `Experiments` snap, Olympus will automatically create a experiment specific dashboard.
The dashboard will have the following widgets:

| Metric                                         | Category  |
| ---------------------------------------------- | --------- |
| DAU (Daily Active Users)                       | Growth    |
| WAU (Weekly Active Users)                      | Growth    |
| MAU (Monthly Active Users)                     | Growth    |
| Retention Rates (D1 - D90)                     | Retention |
| Conversion Rate                                | Revenue   |
| New User Conversion Rate                       | Revenue   |
| ARPDAU (Average Revenue Per Daily Active User) | Revenue   |
| Payer DAU                                      | Revenue   |
| Lifetime Payer DAU                             | Revenue   |
| First Transaction                              | Revenue   |
| Total Revenue                                  | Revenue   |
| Total Transactions                             | Revenue   |
