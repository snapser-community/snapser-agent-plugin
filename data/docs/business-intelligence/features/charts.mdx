# Charts

Olympus also offers a Charts feature to allow custom creation of charts and
other visualization tools to help showcase data and analyze game metrics.

## How it works?

Once a Dataset is created, you can click on the Charts tab and you will see an interface where you can pick
the Dataset to use and pick the type of chart you want to create. Superset offers an extensive variety of visualization tools depending on your needs and type of data you want
to display.

![Olympus Charts](/images/docs/olympus-charts-creation.png)

Once you have chosen the Dataset to display and the chart, hit "Create Chart",
which will take you to the Chart creation page. The UI smartly shows the proper customization depending on
the Chart type selected. This page shows 2 different tabs:

1. **Data:** In this page you can feel free to manage the query and displayed data by different factors
   like the **columns**, **dimensions**, **metrics**, **series**, etc.
2. **Customize:** This is your control panel for how the chart looks and feels. This is where you transition
   from raw data to a polished, presentation-ready visualization. This includes chart titles and labels, color
   scheme, visual elements and formatting.

![Olympus Charts](/images/docs/olympus-charts.png)

Once you are done, you can hit "Update Chart" which will render the chart UI on the right hand side. Once
you are happy with it, you can finally hit save and give it a name. You can then go to the Dashboard tab
and add this chart to a dashboard.
