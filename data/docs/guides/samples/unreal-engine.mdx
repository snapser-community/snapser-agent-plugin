# Unreal Game
This guide will help you set up an Unreal project with Snapser. We have added a very basic project that does an Anonymous login with your Snapser backend. You can use this example to understand how to integrate Snapser into your own game and build on top of it.

<Warning>
  This tutorial is still a work in progress. We are actively working on improving it and adding more features.
</Warning>

## Step 1: Set up your game

To integrate Snapser features into your game, you need to create an account and add your game to it. This section demonstrates how to do that.

<Note>
  If you have already created a game in Snapser, you can skip this step and proceed to the next one.
</Note>

1. **Log in to your Snapser account** at https://snapser.com/login.
2. Navigate to the **Apps dashboard** and click on the **New Game** button located in the upper right corner.
3. **Enter the name of your game** in the designated field. It's advisable to use a name that closely matches your game's title to avoid confusion among your team members. Click **Add** when done.
    ![Add new game name](/images/docs/tutorials/create-snapend-add-game.png)
    <Note>
    Avoid adding prefixes like "dev", "staging", or "prod". Snapser supports multiple environments for each game, allowing you to create a separate custom backend for each stage of your game development.
    </Note>

<Checkpoint step={1}>
  Shortly after, your game will appear in the Apps dashboard, ready for you to build your first custom backend.
</Checkpoint>


## Step 2: Create a Snapend

1. In the **Apps dashboard**, click on the game you have added. This action brings up a view that shows the development, staging, and production environments. Since there are currently no Snapends, let's add one.
![GameClick](/images/docs/tutorials/create-snapend-game.png)
1. In the Development environment, click on **Create a Snapend**.
![GameClick](/images/docs/tutorials/create-snapend-game-home.png)
1. **Enter the name of your Snapend** in the **Name your Snapend** field and click **Continue**.
    ![Name your Snapend](/images/docs/quick-start/name-your-snapend.png)
1. On the next page, select the following snaps:
   1. Authentication
   2. Analytics
    ![Add the Authentication and Analytics Snaps](/images/docs/tutorials/create-snapend-add-snaps.png)
1. Keep clicking **Continue** and then on the Review page click the **Snap It** button. A pop-up window will appear showing you the state of creating your cluster, which takes a moment or two to complete.
1. As Snapser finishes setting up the Snapser cluster in Kubernetes (which includes infrastructure, configuration of Snaps, network and security, and generating your Snapend), click the **App** button to wait for your Snapend to be operational.
![Spinning up cluster](/images/docs/tutorials/create-snapend-cluster-spinup.png)
1. Once the Snapend is ready, you will see a green dot mark on the Snapend widget. This indicates that your Snapend is ready to use.
![Snap Dashboard](/images/docs/tutorials/create-snapend-cluster-ready.png)
1. Click on the Snapend widget to go to the Snapend dashboard.
![Snapend Dashboard](/images/docs/tutorials/create-snapend-snapend-dashboard.png)

## Step 3: Configure Snaps
On your Snapend homepage look for Quick links. Click the **Snaps Configuration** button under **Quick Links** to go to the Snaps configuration home page. Now, lets configure the Snaps one by one.

### A. Authentication Configuration
<Note>
    In our game, we want the user to start playing the game without any login friction. This is why we are going to add the anonymous connector. To add the anonymous connector, please follow the instructions below.
</Note>

1. Click on the **Authentication** widget to open the Auth snaps configuration page.
1. Select the `Authentication > Connectors` tool from the tool navigation and then click on the **Add a connector** button. You will see quite a few connectors in the menu but lets select **Anonymous** and press Save.
![Add Anonymous Authentication](/images/docs/tutorials/snapend-create-admin-auth-anon.png)
1. Then click the back button to go back to the configuration home page.

## Step 4: Download the Snapser SDK
1. On the Snapend home page scroll down to the SDK download widget called **Game Client SDKs**.
    - Select **Unreal - C++** for the platform
    - Click Generate
![Unity SDK](/images/docs/tutorials/unreal-sdk.png)
1. In a few minutes you will see a pop up of a Zip file. Download the zip file and extract it.
1. You will see a folder structure like this:
```bash
  ├── sdk-cpp-ue4-unreal/
    │   ├── Private/
    │   ├── Public/
    │   ├── Snapser.Build.cs
```

<Note>
You will be copying the contents of `sdk-cpp-ue4-unreal` folder into your Unreal projects `Plugins/SnapserPlugin/Source/ThirdParty/sdk-cpp-ue4`folder.
</Note>

<Checkpoint step={4}>
  You now have a SDK that is going to be integrated into your Unreal project. Lets move on to the next step.
</Checkpoint>

## Step 5: Download the Unreal Project
1. Clone this [repo](https://github.com/snapser-community/snapser-demo-unreal-sp).
2. Clone or download this example project and open it in Unreal.
3. After downloading the project you may have a bunch of errors in the console. This is due to the missing Snapser sdk and its dependencies.

## Step 6: Understand the Code

### A. Understand the Snapser Plugin
We have created a Snapser Plugin project that incorporates the raw SDK code that we downloaded in the previous step. This plugin is a C++ plugin that interfaces with the Snapser C++ Module. It exposes a Subsystem to Blueprint, from where Nodes are available for Signing In and Out of the server. It also maintains a set of connection variables such as “IsBanned” and “IsValidated”. The repo has the SnapserProject500.sln file which is the build project for the plugin. It contains the C++ code for both the plugin and the Snapser Module. If you want to build the plugin yourself, you will need to have Visual Studio installed. Just navigate into the root folder, and double-click the “SnapserProject500.sln” file to open it in Visual Studio.
![alt_text](/images/docs/unreal/unreal-plugin.png)
![alt_text](/images/docs/unreal/unreal-code-integration.png)

The plugin itself is not tied down to a specific version, but if you’re wanting to submit the plugin to the marketplace, you’ll need to have a separate build for each version of UE. In the “.uplugin” file, you’ll need to add a engine version field such as:
![alt_text](/images/docs/unreal/unreal-plugin-submit.png)

The fields in this file that can be changed are:
1. Version and VersionName - the plugin version
1. FriendlyName
1. Description
1. Category - can be “RunTime”
1. CreatedBy
1. CreatedByURL
1. MarketplaceURL (if you submit to the marketplace, they will give you a URL for this entry) SupportURL - your own website.


### B. Understand the Snapser Module
1. The Snapser code is added to the plugin in its entirety. This means it can be compiled on any platform, and can be stepped into with the debugging tools.

1. The main Plugin Project is a C++ project, and has the plugin code, and the Snapser module code located in the “plugin” folder. This is the only project that has to be C++ - once the plugin is compiled, it can be installed to Blueprint only Projects on unreal too.
  ![alt_text](/images/docs/unreal/unreal-project-folders.png)

1. The plugin itself is just a simple SubSystem class based on the lifetime of the GameInstance - **SnapserSubsystem.cpp**.

1. The **SnapserPlugin.cpp** file handles the Startup and Shutdown of the plugin.

1. To incorporate the Snapser module, all that is need (seeing as the source files are included in the project) is to add its Module, and the HTTP Module to our dependencies. We do this by adding the following to the **SnapserPlugin.Build.cs** file.

### C. Understand the Snapser Subsystem
1. The Snapser Subsystem is the interface between Blueprints and the Snapser Module.
1. In its present form, it only has a few functions and variables

## Step 7: Update the Code
- Copy the downloaded SDK into the **Plugins/SnapserPlugin/Source/ThirdParty/sdk-cpp-ue4** folder. If there is an existing folder in the repo, you can delete it and replace it with the new SDK code.
```bash
  ├── sdk-cpp-ue4-unreal/ (👈 Copy this folders contents to Plugins/SnapserPlugin/Source/ThirdParty/sdk-cpp-ue4)
    │   ├── Private/
    │   ├── Public/
    │   ├── Snapser.Build.cs
```
- Open the **SnapserProject500.sln** file in Visual Studio.
- On the top navigation bar, select `Build > Build Solution`. This will build the plugin and the Snapser module.
![alt_text](/images/docs/unreal/unreal-build.png)
