# Web Game
This guide will help you set up a Web game with Snapser. This is a simple single player - racing game, that uses Snapser’s authentication, storage and leaderboard snaps. You can use this example to understand how to integrate Snapser into your own game.

## Step 1: Set up your game

To integrate Snapser features into your game, you need to create an account and add your game to it. This section demonstrates how to do that.

<Note>
  If you have already created a game in Snapser, you can skip this step and proceed to the next one.
</Note>

1. **Log in to your Snapser account** at https://snapser.com/login.
2. Navigate to the **Apps dashboard** and click on the **New App** button located in the upper right corner.
3. **Enter the name of your app** in the designated field. It's advisable to use a name that closely matches your applications title to avoid confusion among your team members. Click **Add** when done.
    ![Add new game name](/images/docs/tutorials/create-snapend-add-game.png)
    <Note>
    Avoid adding prefixes like "dev", "staging", or "prod". Snapser supports multiple environments for each game, allowing you to create a separate custom backend for each stage of your development.
    </Note>

<Checkpoint step={1}>
  Shortly after, your app will appear in the Apps dashboard, ready for you to build your first custom backend.
</Checkpoint>


## Step 2: Create a Snapend

1. In the **Apps dashboard**, click on the game you have added. This action brings up a view that shows the development, staging, and production environments. Since there are currently no Snapends, let's add one.
![GameClick](/images/docs/tutorials/create-snapend-game.png)
1. In the Development environment, click on **Create a Snapend**.
![GameClick](/images/docs/tutorials/create-snapend-game-home.png)
1. **Enter the name of your Snapend** in the **Name your Snapend** field and click **Continue**.
    ![Name your Snapend](/images/docs/quick-start/name-your-snapend.png)
1. On the next page, select the following snaps:
   1. Authentication
   2. Leaderboard
   3. Storage
    ![Cluster](/images/docs/tutorials/web-game-snapend.png)
1. Click **Customize** to continue to the next step. In this tutorial, we are not doing any customization and so click the **Review** button to go to the final step.
1. At the final step you can review your Snapend details. Next, click the **Snap It** button. A pop-up window will appear showing you the state of creating your cluster, which takes a moment or two to complete.
1. As Snapser finishes setting up the Snapser cluster in Kubernetes (which includes infrastructure, configuration of Snaps, network and security, and generating your Snapend), click the **App** button to wait for your Snapend to be operational.
1. Once the Snapend is ready, you will see a green dot mark on the Snapend widget. This indicates that your Snapend is ready to use.
![Snap Dashboard](/images/docs/tutorials/create-snapend-cluster-ready.png)
1. Click on the Snapend widget to go to the Snapend dashboard.
![Snapend Dashboard](/images/docs/tutorials/web-game-snapend-dashboard.png)

## Step 3: Configure Snaps
On your Snapend homepage look for Quick links. Click the **Snaps Configuration** button under **Quick Links** to go to the Snaps configuration home page. Now, lets configure the Snaps one by one.

### A. Authentication Configuration
<Note>
    In our Web game, we want the user to start playing the game using username and password as a means to authenticate. This is why we are going to add the `Username password` connector. To add the connector, please follow the instructions below.
</Note>

1. Click on the **Authentication** widget to open the Auth snaps configuration page.
1. Select the `Authentication > Connectors` tool from the tool navigation and then click on the **Add a connector** button. You will see quite a few connectors in the menu but lets select **Username Password** and press Save.
![Add Username Password Authentication](/images/docs/tutorials/snapend-create-admin-auth-uname-password.png)
1. Add a generic regex pattern for now. Allowing the user to enter any password. But do note you should have a strong password policy in production.
    - `Password Settings` - `^[\s\S]*$`
1. Click Save.
1. Then click the back button to go back to the configuration home page.


### B. Leaderboard Configuration
<Note>
    In our Web game, we are going to track laps_completed by every user and then show them a leaderboard of users who have completed the most laps. To add the leaderboards, please follow the instructions below.
</Note>
1. Click on the **Leaderboards** widget to open the Leaderboards snaps configuration page.
1. Here we are going to create one leaderboard: `laps_completed`
1. To create a leaderboard, click on the `Leaderboards` tool from the tool navigation and click on the **+ Leaderboard** button. This will open up a form, where you can add the new leaderboard details. Add the following leaderboards and click save.
   1. `Name` - `laps_completed`
   1. `Description` - `Laps completed by the player`
   1. `Behavior` - `counter` - This is because we want to store counts per player.
   1. `Period - Start time` - Use the date picker to select the current date time, such that the leaderboard is active.
   1. `Period - Type` - `non-recurring` - This is because we want to keep the leaderboard running indefinitely.
    1. `Type` - `global` - This is because we want to have a single leaderboard for all players.
![Leaderboard Config](/images/docs/tutorials/web-game-leaderboard.png)
1. Click Save.
1. Then click the back button to go back to the configuration home page.

### C. Storage Configuration
<Note>
    Storage snap allows you to store any non-structured or structured data for your game. In our case we want to store the fastest time taken by the player to complete the race. We will use a JSON blob to store this data.
</Note>
1. Click on the **Storage** widget to open the Storage snaps configuration page.
1. Select the `Blob Keys` tool from the tool navigation and then click on the **+ Blob Key** button. This will open up a form, where you can add the new blob key. Add the following details in the form and click save.
   1. `Blob Keys` - `user_data`
   1. `Type` - `json`
1. Keep the default values for the rest of the fields.
    ![Storage Config](/images/docs/tutorials/web-game-storage.png)

```typescript
import {
  AuthServiceApi,
  LeaderboardsServiceApi,
  StorageServiceApi,
  AuthUsernamePasswordLoginOperationRequest,
  LeaderboardsGetScoresRequest,
  LeaderboardsIncrementScoreRequest,
  StorageGetJsonBlobRequest,
  StorageReplaceJsonBlobRequest
} from '@/snapser-sdk/apis';

import {
  AuthUsernamePasswordLoginRequest,
  AuthUsernamePasswordLoginResponse,
  LeaderboardsGetScoresResponse,
  IncrementScoreRequest,
  StorageGetJsonBlobResponse,
  LeaderboardsGetScoresRequestRangeEnum,
  StorageGetJsonBlobRequestAccessTypeEnum,
  StorageReplaceJsonBlobRequestAccessTypeEnum,
  ReplaceJsonBlobRequest,
} from '@/snapser-sdk/models';

export interface User {
  id: string;
  username: string;
}

export interface LeaderboardEntry {
  userId: string;
  username: string;
  lapsCompleted: number;
}

export interface UserData {
  fastestThreeLapTime?: number;
}

export class SnapserManager {
  private static authApi = new AuthServiceApi();
  private static leaderboardsApi = new LeaderboardsServiceApi();
  private static storageApi = new StorageServiceApi();
  private static sessionToken: string | null = null;

  // User authentication
  static async login(username: string, password: string): Promise<User | null> {
    try {
      const loginBody: AuthUsernamePasswordLoginRequest = {
        username: username,
        password: password,
        createUser: true
      };

      const request: AuthUsernamePasswordLoginOperationRequest = {
        body: loginBody
      };

      const response: AuthUsernamePasswordLoginResponse = await this.authApi.authUsernamePasswordLogin(request);

      if (response.user) {
        this.sessionToken = response.user.sessionToken || null;
        return {
          id: response.user.id || '',
          username: username
        };
      }

      return null;
    } catch (error) {
      console.error('Login failed:', error);
      return null;
    }
  }

  // Get leaderboard scores
  static async getLeaderboard(): Promise<LeaderboardEntry[]> {
    if (!this.sessionToken) {
      console.error('No session token available');
      return [];
    }

    try {
      const request: LeaderboardsGetScoresRequest = {
        leaderboardName: 'laps_completed',
        range: LeaderboardsGetScoresRequestRangeEnum.Top,
        count: 100,
        token: this.sessionToken
      };

      const response: LeaderboardsGetScoresResponse = await this.leaderboardsApi.leaderboardsGetScores(request);

      return response.userScores?.map(score => ({
        userId: score.userId || '',
        username: score.userId || 'Unknown', // Would need to fetch usernames separately
        lapsCompleted: score.score || 0
      })) || [];
    } catch (error) {
      console.error('Failed to get leaderboard:', error);
      return [];
    }
  }

  // Save number of laps completed to global leaderboard
  static async saveLapsCompleted(userId: string, lapsCompleted: number): Promise<void> {
    if (!this.sessionToken) {
      console.error('No session token available');
      return;
    }

    try {
      const incrementBody: IncrementScoreRequest = {
        delta: lapsCompleted
      };

      const request: LeaderboardsIncrementScoreRequest = {
        leaderboardName: 'laps_completed',
        userId: userId,
        token: this.sessionToken,
        body: incrementBody
      };

      await this.leaderboardsApi.leaderboardsIncrementScore(request);
    } catch (error) {
      console.error('Failed to save laps completed:', error);
    }
  }

  // Save fastest time for three laps to user's personal data
  static async saveFastestTime(userId: string, timeInSeconds: number): Promise<void> {
    if (!this.sessionToken) {
      console.error('No session token available');
      return;
    }

    try {
      const userData = { fastestThreeLapTime: timeInSeconds };

      const replaceBody: ReplaceJsonBlobRequest = {
        value: userData,
        create: true
      };

      const request: StorageReplaceJsonBlobRequest = {
        ownerId: userId,
        accessType: StorageReplaceJsonBlobRequestAccessTypeEnum.Protected,
        jsonBlobKey: 'user_data',
        token: this.sessionToken,
        body: replaceBody
      };

      await this.storageApi.storageReplaceJsonBlob(request);
    } catch (error) {
      console.error('Failed to save fastest time:', error);
    }
  }

  // Get user's personal data including fastest time
  static async getUserData(userId: string): Promise<UserData> {
    if (!this.sessionToken) {
      console.error('No session token available');
      return {};
    }

    try {
      const request: StorageGetJsonBlobRequest = {
        ownerId: userId,
        accessType: StorageGetJsonBlobRequestAccessTypeEnum.Protected,
        jsonBlobKey: 'user_data',
        token: this.sessionToken
      };

      const response: StorageGetJsonBlobResponse = await this.storageApi.storageGetJsonBlob(request);

      return (response.value as UserData) || {};
    } catch (error) {
      console.error('Failed to get user data:', error);
      return {};
    }
  }
}
```
