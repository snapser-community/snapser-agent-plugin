# Web App - Social Todo
This guide will help you set up a Web app with Snapser. This app allows users to create an account, add tasks to their todo list, make todos public so as to share them with other users, and view other users public todo lists.

## Step 1: Set up your app

To integrate Snapser features into your app, you need to create an account and add your app to it. This section demonstrates how to do that.

<Note>
  If you have already created an app in Snapser, you can skip this step and proceed to the next one.
</Note>

1. **Log in to your Snapser account** at https://snapser.com/login.
2. Navigate to the **Apps dashboard** and click on the **New App** button located in the upper right corner.
3. **Enter the name of your app** in the designated field. It's advisable to use a name that closely matches your applications title to avoid confusion among your team members. Click **Add** when done.
    ![Add new game name](/images/docs/tutorials/create-snapend-add-game.png)
    <Note>

## Step 3: Configure Snaps
On your Snapend homepage look for Quick links. Click the **Snaps Configuration** button under **Quick Links** to go to the Snaps configuration home page. Now, lets configure the Snaps one by one.

### A. Authentication Configuration
<Note>
    In our Web app, we want the user to start using the app using username and password as a means to authenticate. This is why we are going to add the `Username password` connector. To add the connector, please follow the instructions below.
</Note>

1. Click on the **Authentication** widget to open the Auth snaps configuration page.
1. Select the `Authentication > Connectors` tool from the tool navigation and then click on the **Add a connector** button. You will see quite a few connectors in the menu but lets select **Username Password** and press Save.
![Add Username Password Authentication](/images/docs/tutorials/social-todo-user-pass-setup.png)
1. Click `Any Characters` for the password policy and then set the `Min` to `1` and `Max` to `64`.
    <Note>
      In real world applications, you should set a strong password policy. Here we are keeping it simple for demo purposes.
    </Note>
1. Click Save.
1. Then click the back button to go back to the configuration home page.


### B. Storage Configuration
<Note>
    Storage snap allows you to store any non-structured or structured data for your app. In our case we want to store the a blob for storing users private and public todo lists.
</Note>
1. Click on the **Storage** widget to open the Storage snaps configuration page.
1. Select the `Blob Keys` tool from the tool navigation and then click on the **+ Blob Key** button. This will open up a form, where you can add the new blob key.
1. Lets add the private todo list blob key first.
   1. `Blob Keys` - `todo_private`
   1. `Type` - `json`
   1. `Access Scope` - `external`
   1. `Access Type` - `private`
   1. Click Save.
   ![Storage Private Config](/images/docs/tutorials/social-todo-storage-private.png)
1. Now lets add the public todo list blob key.
    1. `Blob Keys` - `todo_public`
    1. `Type` - `json`
   1. `Access Scope` - `external`
   1. `Access Type` - `public`
    1. Click Save.
    ![Storage Public Config](/images/docs/tutorials/social-todo-storage-public.png)

import { AuthLogoutRequest, AuthServiceApi, AuthUsernamePasswordLoginOperationRequest, AuthUsernamePasswordLoginRequest, AuthUsernamePasswordLoginResponse, ReplaceJsonBlobRequest, StorageGetJsonBlobRequest, StorageGetJsonBlobRequestAccessTypeEnum, StorageGetJsonBlobResponse, StorageReplaceJsonBlobRequest, StorageReplaceJsonBlobRequestAccessTypeEnum, StorageServiceApi } from "@/snapser-sdk";

// src/services/SnapserManager.ts
export type TodoItem = {
  id: string;
  text: string;
  done: boolean;
  createdAt: string;
  updatedAt: string;
};

export type TodoList = {
  id: string;
  slug: string;
  title: string;
  description?: string;
  items: TodoItem[];
  updatedAt: string;
};

export type SavedList = {
  todos: TodoList[];
}

export class SnapserManager {
  private static authApi = new AuthServiceApi();
  private static storageApi = new StorageServiceApi();
  private static currentUserId: string | null = null;
  private static sessionToken: string | null = null;

  static async login(username: string, password: string): Promise<{ userId: string }> {
    try {
      const loginBody: AuthUsernamePasswordLoginRequest = {
        username: username,
        password: password,
        createUser: false,
      };

      const request: AuthUsernamePasswordLoginOperationRequest = {
        body: loginBody
      };

      const response: AuthUsernamePasswordLoginResponse = await this.authApi.authUsernamePasswordLogin(request);

      if (response.user) {
        //Save to local storage or memory
        localStorage.setItem('sessionToken', response.user.sessionToken || '');
        localStorage.setItem('currentUserId', response.user.id || '');
        this.sessionToken = response.user.sessionToken || null;
        this.currentUserId = response.user.id || null;
        return {
          userId: response.user.id || '',
        };
      }
      throw new Error("Invalid credentials");
    } catch (error) {
      console.error('Login failed:', error);
      return null;
    }
  }

  static async signup(username: string, password: string): Promise<{ userId: string }> {
    try {
      const loginBody: AuthUsernamePasswordLoginRequest = {
        username: username,
        password: password,
        createUser: true,
      };

      const request: AuthUsernamePasswordLoginOperationRequest = {
        body: loginBody
      };

      const response: AuthUsernamePasswordLoginResponse = await this.authApi.authUsernamePasswordLogin(request);

      if (response.user) {
        localStorage.setItem('sessionToken', response.user.sessionToken || '');
        localStorage.setItem('currentUserId', response.user.id || '');
        this.currentUserId = response.user.id || null;
        this.sessionToken = response.user.sessionToken || null;
        return {
          userId: response.user.id || '',
        };
      }
      throw new Error("Invalid credentials");
    } catch (error) {
      console.error('Login failed:', error);
      return null;
    }
  }

  static getCurrentUserId(): string | null {
    if (!this.currentUserId) {
      this.currentUserId = localStorage.getItem('currentUserId');
    }
    if (!this.sessionToken) {
      this.sessionToken = localStorage.getItem('sessionToken');
    }
    return this.currentUserId;
  }

  static async logout(): Promise<boolean> {
    const authLogoutRequestData: AuthLogoutRequest = {
      token: this.sessionToken || undefined,
      token2: this.sessionToken || undefined,
    };
    await this.authApi.authLogout(authLogoutRequestData);
    this.sessionToken = null;
    this.currentUserId = null;
    localStorage.removeItem('sessionToken');
    localStorage.removeItem('currentUserId');
    return true
  }

  // JSON blob getters (later will fetch from backend)
  static async getPublicLists(userId: string): Promise<TodoList[]> {
    if (!this.sessionToken) {
      console.error('No session token available');
      return [];
    }

    try {
      const request: StorageGetJsonBlobRequest = {
        ownerId: userId,
        accessType: StorageGetJsonBlobRequestAccessTypeEnum.Protected,
        jsonBlobKey: 'todo_public',
        token: this.sessionToken
      };

      const response: StorageGetJsonBlobResponse = await this.storageApi.storageGetJsonBlob(request);

      const todosResponse = (response.value as SavedList) || { todos: [] };
      return (todosResponse.todos as TodoList[]) || [];
    } catch (error) {
      console.error('Failed to get user data:', error);
      return [];
    }
  }

  static async getPrivateLists(): Promise<TodoList[]> {
    if (!this.sessionToken || !this.currentUserId) {
      console.error('No session token available');
      return [];
    }

    try {
      const request: StorageGetJsonBlobRequest = {
        ownerId: this.currentUserId,
        accessType: StorageGetJsonBlobRequestAccessTypeEnum.Private,
        jsonBlobKey: 'todo_private',
        token: this.sessionToken
      };

      const response: StorageGetJsonBlobResponse = await this.storageApi.storageGetJsonBlob(request);
      const todosResponse = (response.value as SavedList) || { todos: [] };
      return (todosResponse.todos as TodoList[]) || [];
    } catch (error) {
      console.error('Failed to get user data:', error);
      return [];
    }
  }

  static async saveList(visibility: "public" | "private", newList: TodoList[]): Promise<void> {
    if (!this.sessionToken || !this.currentUserId) {
      console.error('No session token available');
      return;
    }

    try {
      const newSavedList: SavedList = {
        todos: newList
      }
      // Save to backend
      const replaceBody: ReplaceJsonBlobRequest = {
        value: newSavedList,
        create: true
      };

      const request: StorageReplaceJsonBlobRequest = {
        ownerId: this.currentUserId,
        accessType: visibility === 'public' ? StorageReplaceJsonBlobRequestAccessTypeEnum.Protected : StorageReplaceJsonBlobRequestAccessTypeEnum.Private,
        jsonBlobKey: visibility === 'public' ? 'todo_public' : 'todo_private',
        token: this.sessionToken,
        body: replaceBody
      };

      await this.storageApi.storageReplaceJsonBlob(request);
    } catch (error) {
      console.error('Failed to save fastest time:', error);
    }
  }

  static async getList(
    userId: string,
    visibility: "public" | "private",
    slug: string,
    asUserId?: string
  ): Promise<TodoList | null> {
    if (visibility === "private" && asUserId !== userId) {
      throw new Error("Unauthorized");
    }

    const lists = visibility === "public"
      ? await this.getPublicLists(userId)
      : await this.getPrivateLists();

    return lists.find(list => list.slug === slug) || null;
  }

  // CRUD for lists (later persist to backend)
  static async createList(
    visibility: "public" | "private",
    data: { title: string; description?: string; items?: { text: string }[] }
  ): Promise<TodoList | null> {
    if (!this.sessionToken || !this.currentUserId) {
      console.error('No session token available');
      return null;
    }

    const slug = data.title.toLowerCase().replace(/[^a-z0-9]+/g, '-').replace(/^-|-$/g, '');
    const newListItem: TodoList = {
      id: `${visibility}_${Date.now()}`,
      slug,
      title: data.title,
      description: data.description,
      updatedAt: new Date().toISOString(),
      items: (data.items || []).map((item, index) => ({
        id: `todo_${Date.now()}_${index}`,
        text: item.text,
        done: false,
        createdAt: new Date().toISOString(),
        updatedAt: new Date().toISOString(),
      })),
    };
    let newList: TodoList[] = []
    if (visibility === "public") {
      newList = await this.getPublicLists(this.currentUserId);
      newList.push(newListItem);
    } else {
      newList = await this.getPrivateLists();
      newList.push(newListItem);
    }
    await this.saveList(visibility, newList);
    return newListItem;
  }

  static async updateList(
    visibility: "public" | "private",
    listId: string,
    patch: Partial<Pick<TodoList, "title" | "description" | "items">>
  ): Promise<TodoList> {
    if(!this.sessionToken || !this.currentUserId) {
      console.error('No session token available');
      throw new Error("Unauthorized");
    }

    const lists = visibility === "public"
      ? await this.getPublicLists(this.currentUserId)
      : await this.getPrivateLists();

    // const lists = visibility === "public" ? user.publicLists : user.privateLists;
    const listIndex = lists.findIndex(list => list.id === listId);

    if (listIndex === -1) throw new Error("List not found");

    const updatedList = {
      ...lists[listIndex],
      ...patch,
      updatedAt: new Date().toISOString(),
    };

    // Update slug if title changed
    if (patch.title) {
      updatedList.slug = patch.title.toLowerCase().replace(/[^a-z0-9]+/g, '-').replace(/^-|-$/g, '');
    }

    lists[listIndex] = updatedList;
    await this.saveList(visibility, lists);

    return updatedList;
  }

  static async deleteList(
    visibility: "public" | "private",
    listId: string
  ): Promise<{ success: true }> {
    if (!this.sessionToken || !this.currentUserId) {
      console.error('No session token available');
      throw new Error("Unauthorized");
    }

    const lists = visibility === "public"
      ? await this.getPublicLists(this.currentUserId)
      : await this.getPrivateLists();
    const listIndex = lists.findIndex(list => list.id === listId);

    if (listIndex === -1) throw new Error("List not found");

    lists.splice(listIndex, 1);
    await this.saveList(visibility, lists);
    return { success: true };
  }

  // Helper methods for todo items
  static async addTodoItem(
    userId: string,
    visibility: "public" | "private",
    listId: string,
    text: string
  ): Promise<TodoItem> {
    if(!this.sessionToken || !this.currentUserId) {
      console.error('No session token available');
      throw new Error("Unauthorized");
    }

    const lists = visibility === "public"
      ? await this.getPublicLists(this.currentUserId)
      : await this.getPrivateLists();
    const list = lists.find(l => l.id === listId);

    if (!list) throw new Error("List not found");

    const newItem: TodoItem = {
      id: `todo_${Date.now()}`,
      text,
      done: false,
      createdAt: new Date().toISOString(),
      updatedAt: new Date().toISOString(),
    };

    list.items.push(newItem);
    list.updatedAt = new Date().toISOString();
    await this.saveList(visibility, lists);

    return newItem;
  }

  static async updateTodoItem(
    visibility: "public" | "private",
    listId: string,
    itemId: string,
    patch: Partial<Pick<TodoItem, "text" | "done">>
  ): Promise<TodoItem> {
    if(!this.sessionToken || !this.currentUserId) {
      console.error('No session token available');
      throw new Error("Unauthorized");
    }

    const lists = visibility === "public"
      ? await this.getPublicLists(this.currentUserId)
      : await this.getPrivateLists();
    const list = lists.find(l => l.id === listId);

    if (!list) throw new Error("List not found");

    const itemIndex = list.items.findIndex(item => item.id === itemId);
    if (itemIndex === -1) throw new Error("Item not found");

    const updatedItem = {
      ...list.items[itemIndex],
      ...patch,
      updatedAt: new Date().toISOString(),
    };

    list.items[itemIndex] = updatedItem;
    list.updatedAt = new Date().toISOString();
    await this.saveList(visibility, lists);
    return updatedItem;
  }

  static async deleteTodoItem(
    userId: string,
    visibility: "public" | "private",
    listId: string,
    itemId: string
  ): Promise<{ success: true }> {
    if(!this.sessionToken || !this.currentUserId) {
      console.error('No session token available');
      throw new Error("Unauthorized");
    }

    const lists = visibility === "public"
      ? await this.getPublicLists(this.currentUserId)
      : await this.getPrivateLists();
    const list = lists.find(l => l.id === listId);

    if (!list) throw new Error("List not found");

    const itemIndex = list.items.findIndex(item => item.id === itemId);
    if (itemIndex === -1) throw new Error("Item not found");

    list.items.splice(itemIndex, 1);
    list.updatedAt = new Date().toISOString();
    await this.saveList(visibility, lists);
    return { success: true };
  }
}
