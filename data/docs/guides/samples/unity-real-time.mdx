# Unity Realtime Multiplayer Game
This guide will help you set up a Unity game with Snapser. This is a realtime multiplayer - Red light green light from Squidgames, that uses Snapser’s authentication, hermes (websocket), eventbus, matchmaker, and Mirror Networking. This example is to showcase how to use Snapser in Unity and is not a production ready game.

<Warning>
    This tutorial requires the `Eventbus` snap which is only available to the Premium Tier customers.
</Warning>

## Step 1: Set up your game

To integrate Snapser features into your game, you need to create an account and add your game to it. This section demonstrates how to do that.

<Note>
  If you have already created a game in Snapser, you can skip this step and proceed to the next one.
</Note>

1. **Log in to your Snapser account** at https://snapser.com/login.
2. Navigate to the **Apps dashboard** and click on the **New Game** button located in the upper right corner.
3. **Enter the name of your game** in the designated field. It's advisable to use a name that closely matches your game's title to avoid confusion among your team members. Click **Add** when done.
    ![Add new game name](/images/docs/tutorials/create-snapend-add-game.png)
    <Note>
    Avoid adding prefixes like "dev", "staging", or "prod". Snapser supports multiple environments for each game, allowing you to create a separate custom backend for each stage of your game development.
    </Note>

<Checkpoint step={1}>

</Checkpoint>

## Step 3: Configure Snaps
On your Snapend homepage look for Quick links. Click the **Snaps Configuration** button under **Quick Links** to go to the Snaps configuration home page. Now, lets configure the Snaps one by one.

### A. Authentication Configuration
<Note>
    In our Unity game, we want the user to start playing the game without any login friction. This is why we are going to add the anonymous connector. To add the anonymous connector, please follow the instructions below.
</Note>

1. Click on the **Snaps Configuration** button.
1. Select the `Authentication > Connectors` tool from the tool navigation and then click on the **Add a connector** button. You will see quite a few connectors in the menu but lets select **Anonymous** and press Save.
![Add Anonymous Authentication](/images/docs/tutorials/snapend-create-admin-auth-anon.png)
1. Then click the back button to go back to the configuration home page.

### B. Matchmaking Configuration
<Note>
    In our Unity game, we want to setup a Matchmaking profile so that user can be matched with other players. To add the matchmaking profile, please follow the instructions below.
</Note>
1. Click on the **Snaps Configuration** button.
1. Select the `Matchmaking > Match Profiles` tool from the tool navigation.
1. Here we are going to create one matchmaking profile. Matchmaking profile is what tells the snap the criterion it should look at to match players. Click on the **+ Add Matchmaking profile** button and you will see a pop up form.
1. Enter the following details in the form:
    - **Name**: `my_profile`
    - **Description**: `Unity RT Demo Profile`
    - **Min Players**: `2`
    - **Max Players**: `4`
    - **Match Allocation**: Pick `relay` from the dropdown.
![Snapend Dashboard](/images/docs/tutorials/unity-rt-matchmaking.png)

### C. Eventbus Configuration
1. Click on the **Snaps Configuration** button.
1. Select the `Eventbus > Websocket` tool from the tool navigation.
1. Toggle all the Events for Matchmaking to `enabled`.

<Note>
    Why did we add all other snaps when we are only configuring Auth and Matchmaking? The reason is that we will be expanding this tutorial to include more features like Leaderboards, Statistics, and Profiles. So we are adding all the snaps now so that you can follow along in the future.
</Note>

## Step 8: Understand the Code
1. Understand how Mirror works. You can check the Mirror documentation [here](https://mirror-networking.gitbook.io/docs).
1. You should look at **SnapserManager.cs**. This class acts as the link between the game logic and the Snapser sdk.
1. For the realtime code, to understand how data packets are transferred between peers and the host, open **HermesTransport.cs** in the example project. It is a child class of **Transport.cs** which Mirror uses for data exchange.
1. Next, understand the **WebsocketConnectionManager.cs** It it mainly responsible for the following:
    - Create the websocket connection with `Connect(string address)`
    - Handle connection events such as `OnClose`, `OnOpen`, `OnError` and so on.
    - Automatically reconnect when the connection drops, like during a Snapend upgrade.
    - Dispatch message queue in `**FixedUpdate()**`.
    - Receive and relay incoming messages from the websocket to the corresponding message handlers in **RegisterMessageHandlers**
```csharp
public class WebsocketConnectionManager : MonoBehaviour
{
    private WebSocket conn;

    private string lastAddress;
    private bool intentionalClose;
    private bool migrating;
    private int reconnectAttempts;
    private const int MaxReconnectAttempts = 8;

    public static event UnityAction OnConnectionOpened;
    public static event UnityAction OnConnectionClosed;
    public static event UnityAction OnConnectionError;

    private void Awake()
    {
        enabled = false;
        DontDestroyOnLoad(this);
    }

    private void OnDestroy()
    {
        enabled = false;
        intentionalClose = true;
        conn.Close();
    }

    private void OnApplicationQuit()
    {
        enabled = false;
        intentionalClose = true;
        conn.Close();
    }

    private void FixedUpdate()
    {
        if (conn.State == WebSocketState.Open)
            conn.DispatchMessageQueue();
    }

    public void Connect(string address)
    {
        Debug.Log($"Connecting to {address}...");
        lastAddress = address;
        intentionalClose = false;
        conn = new WebSocket(address);

        // Ride that monobehavior update loop baby
        // WebsocketUpdater.Initialize(conn);
        enabled = true;

        RegisterDefaultHandlers();
        RegisterMessageHandlers();

        conn.Connect();
    }

    public bool IsConnected()
    {
        return conn is { State : WebSocketState.Open };
    }

    public void Disconnect()
    {
        intentionalClose = true;
        conn.Close();
    }

    private IEnumerator Reconnect(bool immediate)
    {
        if (reconnectAttempts >= MaxReconnectAttempts)
        {
            Debug.LogError("WebSocket reconnect attempts exhausted.");
            OnConnectionError?.Invoke();
            yield break;
        }
        reconnectAttempts++;

        if (!immediate)
        {
            // Exponential backoff with jitter, capped at 30 seconds
            float backoff = Mathf.Min(Mathf.Pow(2f, reconnectAttempts), 30f);
            yield return new WaitForSeconds(backoff + Random.Range(0f, backoff * 0.5f));
        }

        Connect(lastAddress);
    }

    private void RegisterDefaultHandlers()
    {
        conn.OnOpen += () =>
        {
            // Listeners on OnConnectionOpened should re-establish session-scoped
            // state (presence, event expectations) in case this is a reconnect.
            reconnectAttempts = 0;
            migrating = false; // clear the drain guard so a future drain is handled
            OnConnectionOpened?.Invoke();
            Debug.Log("Connection opened!");
        };

        conn.OnClose += e =>
        {
            OnConnectionClosed?.Invoke();

            if (intentionalClose)
            {
                Debug.Log("WebSocket closed by client.");
                return;
            }

            // 1001 (going away) and 1006 (service restart) mean Hermes is being
            // upgraded or restarted. A replacement instance is already serving
            // traffic, so reconnect immediately - this is routine, not an error.
            var code = (int)e;
            bool serverMaintenance = code == 1001 || code == 1006;
            Debug.Log($"WebSocket closed (code {code}). Reconnecting...");
            StartCoroutine(Reconnect(serverMaintenance));
        };

        conn.OnError += e =>
        {
            OnConnectionError?.Invoke();
            Debug.LogError("WebSocket error! " + e.ToString());
        };

        Handlers.MatchHandler.Instance.SetSendClientMessage(async message =>
                                                            {
                                                                // Debug.Log("Sending match client message to server ...");
                                                                if (conn.State == WebSocketState.Open)
                                                                    await conn.Send(message);
                                                            });

        Handlers.MatchmakingHandler.Instance.SetSendClientMessage(async message =>
                                                                  {
                                                                      Debug.Log("Sending matchmaking client message to server ...");
                                                                      if (conn.State == WebSocketState.Open)
                                                                          await conn.Send(message);
                                                                  });

        Handlers.ErrorHandler.Instance.OnError += (_, args) =>
        {
            Debug.LogError("Error received from server! " + args.Error.Message + " " + args.Error.Code);
        };
    }

    private void RegisterMessageHandlers()
    {
        conn.OnMessage += message =>
        {
            var serverMessage = ServerMessage.Parser.ParseFrom(message);
            switch (serverMessage.MessageType)
            {
            case MessageType.GoingAway:
                // Hermes is draining this instance for an upgrade or restart. Migrate to a
                // healthy instance now instead of waiting for the force-close at the end of the
                // grace window. Hermes re-sends this message as the deadline nears, so the
                // `migrating` guard ensures we only start one reconnect.
                var goingAway = serverMessage.GoingAway;
                Debug.Log($"Hermes going away in {goingAway.SecondsUntilForceClose}s ({goingAway.Reason}). Migrating...");
                if (!migrating)
                {
                    migrating = true;
                    StartCoroutine(Reconnect(true));
                }
                break;
            case MessageType.Error:
                Handlers.ErrorHandler.Instance.HandleServerMessage(serverMessage);
                break;
            case MessageType.Chat:
                break;
            case MessageType.Match:
                Handlers.MatchHandler.Instance.HandleServerMessage(serverMessage);
                break;
            case MessageType.Matchmaking:
                Handlers.MatchmakingHandler.Instance.HandleServerMessage(serverMessage);
                break;
            case MessageType.Party:
                break;
            default:
                Debug.LogWarning("Unknown message type! " + serverMessage.MessageType);
                break;
            }
        };
    }
}
```
<Note>
  Hermes closes connections with code 1001 or 1006 whenever your Snapend is upgraded, so clients
  must reconnect automatically. See the
  [Hermes Connection Lifecycle](/docs/infra/snaps/hermes#connection-lifecycle) for the full
  reconnect contract.
</Note>

Lastly, understand **SnapshipNetworkManager.cs** which handles the multiplayer gameplay affecting events on the Mirror side of things.
```csharp
public class SpaceshipNetworkManager : NetworkManager
{
    public new static SpaceshipNetworkManager singleton { get; private set; }

    [SerializeField, Required] Transform playerSpawnPoint, lightControllerSpawnPoint;
    [SerializeField, Required]
    private List<Color> spaceshipColors;

    private GameObject lightController;
    HermesTransport hermesTransport;

    public HermesTransport HermesTransport => hermesTransport;

    private SnapserManager snapserManager;
    public SnapserManager SnapserManager => snapserManager;
    private List<GameObject> players = new List<GameObject>();

    public override void Awake()
    {
        base.Awake();
        singleton = this;
        hermesTransport = GetComponent<HermesTransport>();
        snapserManager = new SnapserManager(networkAddress);
    }

    public override void OnServerAddPlayer(NetworkConnectionToClient conn)
    {
        // Add players on all clients after the client is started and add to the server
        int playerToBeCreatedCount = numPlayers + 1;
        Vector3 startPosition = new Vector3(playerSpawnPoint.position.x, playerSpawnPoint.position.y - (playerToBeCreatedCount - 1) * 8, playerSpawnPoint.position.z);
        GameObject player = Instantiate(playerPrefab, startPosition, playerSpawnPoint.rotation);
        players.Add(player);
        // Spaceship spaceship = player.GetComponent<Spaceship>();
        // spaceship.InitializeSpaceship(spaceshipColors[numPlayers]);
        NetworkServer.AddPlayerForConnection(conn, player);
        Debug.Log("Player " + numPlayers + " of " + hermesTransport.RelayConnectionsCount + " created at location " + player.transform.position);

        // When all players have been instantiated, instantiated the game light controller for all clients
        if (numPlayers == hermesTransport.RelayConnectionsCount)
        {
            Debug.Log("Creating the game light after " + numPlayers + " of " + hermesTransport.RelayConnectionsCount + " joined and were created.");
            lightController = Instantiate(spawnPrefabs.Find(prefab => prefab.name == "GameLightController"));
            Vector3 lightControllerPosition = lightController.transform.position;
            lightController.transform.position = new Vector3(lightControllerSpawnPoint.position.x,
                                                             lightControllerPosition.y, lightControllerPosition.z);
            NetworkServer.Spawn(lightController);
        }
    }

    public override void OnServerDisconnect(NetworkConnectionToClient conn)
    {
        // Destroy the game light controller when server disconnects
        if (lightController != null)
            NetworkServer.Destroy(lightController);

        // Call base functionality (actually destroys the player)
        base.OnServerDisconnect(conn);
    }

    public Color GetSpaceshipColor(GameObject player)
    {
        if (players.Contains(player))
        {
            int playerIndex = players.IndexOf(player) % spaceshipColors.Count;
            return spaceshipColors[playerIndex];
        }

        Debug.LogWarning("Game object not found in the player game object lists ");
        return Random.ColorHSV(0f, 1f, 1f, 1f, 0.5f, 1f);
    }
}
```
