# Mobile App - Social Network
This guide will help you set up a Mobile app built using expo and Snapser as the backend.
We will build a simple Social Network app that allows users to sign up, add friends, send them good vibes and manage their profile. We will use the Snapser Trackables energy system to replenish total vibes a user can send in a day. This basic app demonstrates how to use Snapser's Authentication system, Profiles snap for managing user profiles, Social graph snap for managing friends, Inbox to send user messages and Trackables snap for managing the energy system.

<Warning>
  This tutorial requires 6 snaps, which is one more than the free tier allows. You can buy additional snap or then just follow along without creating the snaps.
</Warning>

<Note>

</Note>

2. Navigate to the **Apps dashboard** and click on the **New App** button located in the upper right corner.

## Step 3: Configure Snaps
On your Snapend homepage look for Quick links. Click the **Snaps Configuration** button under **Quick Links** to go to the Snaps configuration home page. Now, lets configure the Snaps one by one.

### A. Authentication Configuration
<Note>
    In our Web app, we want the user to start using the app using username and password as a means to authenticate. This is why we are going to add the `Username password` connector. To add the connector, please follow the instructions below.
</Note>

1. Click on the **Authentication** widget to open the Auth snaps configuration page.
1. Select the `Authentication > Connectors` tool from the tool navigation and then click on the **Add a connector** button. You will see quite a few connectors in the menu but lets select **Username Password** and press Save.
![Add Username Password Authentication](/images/docs/tutorials/social-app-auth-one.png)
1. Click `Any Characters` for the password policy and then set the `Min` to `1` and `Max` to `64`.
    <Note>
      In real world applications, you should set a strong password policy. Here we are keeping it simple for demo purposes.
    </Note>
1. Click Save.
1. Then click the back button to go back to the configuration home page.

### B. Inbox Configuration
<Note>
    Inbox snap allows you to send messages between users. In our case we want to allow users to send "vibes" to their friends.
</Note>
1. Click on the **Inbox** widget to open the Inbox snaps configuration page.
1. Select the `Inbox > Inbox Settings > User Messages` tool from the tool navigation.
1. Toggle the `Enabled` button to active, to enable user messages.
1. Click Save.
![Inbox](/images/docs/tutorials/social-app-inbox-one.png)

### C. Profiles Configuration
<Note>
    Profiles snap allows you to store user profile information. In our case we want to store the users first name, last name and profile pic.
</Note>
1. Click on the **Profiles** widget to open the Profiles snaps configuration page.
1. Select the `Profiles > Attributes` tool from the tool navigation and then click on the **+ Profile Attribute** button. This will open up a form where you can add a profile field.
1. Lets add a profile attribute to store the users first name, last name and profile picture.
#### First Name
   1. `Attribute Name` - `first_name`
   1. `Category` - `Strictly Searchable`
   1. `Type` - `text`
   1. `Regex` - `Any Characters`, `Min` - `1`, `Max` - `100`
   1. `Presence` - `Required`
   1.  `Access` - `public`
   1. Click Save.

#### Last Name
   1. `Attribute Name` - `last_name`
   1. `Category` - `Strictly Searchable`
   1. `Type` - `text`
   1. `Regex` - `Any Characters`, `Min` - `1`, `Max` - `100`
   1. `Presence` - `Required`
   1.  `Access` - `public`
   1. Click Save.

#### Profile Picture
   1. `Attribute Name` - `profile_pic`
   1. `Category` - `Regular`
   1. `Type` - `text`
   1. `Regex` - `Any Characters`, `Min` - `1`, `Max` - `500`
   1. `Presence` - `Required` - `Unchecked`
   1.  `Access` - `public`
   1. Click Save.
    <Note>
      In a real world application, you would want to store the profile picture in the assets snap. Here we are keeping it simple for demo purposes.
    </Note>
![Profile Attributes](/images/docs/tutorials/social-app-profile-one.png)


### D. Trackables Configuration
<Note>
    Trackables snap allows you to create and manage trackable items. In our case we want to create a trackable item called "vibes" that replenishes every day.  Users can send vibes to their friends and the total number of vibes a user can send is limited by the number of vibes they have.
</Note>
1. Click on the **Trackables** widget to open the Trackables snaps configuration page.
1. Select the `Trackables > Energy` tool from the tool navigation and then click on the **+ Energy** button. This will open up a form where you can add a trackable item.
1. Lets add a trackable item for sending vibes.
   1. `Name` - `good_vibes`
   1. `Access > Scope` - `external`
   1. `Parameters - Max Energy` - `500`
   1. `Parameters - Seconds to Regenerate` - `3600`
   1. `Default` - `5`
   1. `Overflow - Allow overflow` - `disabled`
   1. Click Save.
![Trackable Attributes](/images/docs/tutorials/social-app-trackables-energy-one.png)

  private static currentUserId: string | null = null;
  private static sessionToken: string | null = null;
  private static currentUserName: string | null = null;

  // TODO: wire to real backend auth later
  static async login(username: string, password: string): Promise<{ userId: string } | null> {
    try {
      const loginBody: AuthUsernamePasswordLoginRequest = {
        username: username,
        password: password,
        createUser: false,
      };

      const request: AuthUsernamePasswordLoginOperationRequest = {
        body: loginBody
      };

      const response: AuthUsernamePasswordLoginResponse = await this.authApi.authUsernamePasswordLogin(request);

      if (response.user) {
        //Save to local storage or memory
        localStorage.setItem('sessionToken', response.user.sessionToken || '');
        localStorage.setItem('currentUserId', response.user.id || '');
        localStorage.setItem('currentUserName', username);
        this.sessionToken = response.user.sessionToken || null;
        this.currentUserId = response.user.id || null;
        this.currentUserName = username;
        return {
          userId: response.user.id || '',
        };
      }
      throw new Error("Invalid credentials");
    } catch (error) {
      console.error('Login failed:', error);
      return null;
    }
  }

  static async signup(username: string, password: string): Promise<{ userId: string } | null> {
    try {
      const loginBody: AuthUsernamePasswordLoginRequest = {
        username: username,
        password: password,
        createUser: true,
      };

      const request: AuthUsernamePasswordLoginOperationRequest = {
        body: loginBody
      };

      const response: AuthUsernamePasswordLoginResponse = await this.authApi.authUsernamePasswordLogin(request);

      if (response.user) {
        localStorage.setItem('sessionToken', response.user.sessionToken || '');
        localStorage.setItem('currentUserId', response.user.id || '');
        localStorage.setItem('currentUserName', username);
        this.currentUserId = response.user.id || null;
        this.sessionToken = response.user.sessionToken || null;
        this.currentUserName = username;
        return {
          userId: response.user.id || '',
        };
      }
      throw new Error("Invalid credentials");
    } catch (error) {
      console.error('Login failed:', error);
      return null;
    }
  }

  static getCurrentUserId(): string | null {
    if (!this.currentUserId) {
      this.currentUserId = localStorage.getItem('currentUserId');
    }
    if (!this.sessionToken) {
      this.sessionToken = localStorage.getItem('sessionToken');
    }
    if (!this.currentUserName) {
      this.currentUserName = localStorage.getItem('currentUserName');
    }
    return this.currentUserId;
  }

    if (!this.currentUserId) {

    }

  static async logout(): Promise<boolean> {
    const authLogoutRequestData: AuthLogoutRequest = {
      token: this.sessionToken || '',
      token2: this.sessionToken || '',
    };
    await this.authApi.authLogout(authLogoutRequestData);
    this.sessionToken = null;
    this.currentUserId = null;
    this.currentUserName = null;
    localStorage.removeItem('sessionToken');
    localStorage.removeItem('currentUserId');
    localStorage.removeItem('currentUserName');
    return true
  }

  // JSON blob getters (later will fetch from backend)
  static async getVibes(markReadOnRetrieval: boolean = false): Promise<VibeMessage[]> {
    if(!this.sessionToken || !this.currentUserId) {
      return [];
    }
    try {
      const inboxGetMessageRequest: InboxGetMessagesRequest = {
        userId: this.currentUserId || '',
        token: this.sessionToken || '',
      }
      const vibeMessagesResponse: InboxGetMessagesResponse = await this.inboxApi.inboxGetMessages(inboxGetMessageRequest)
        if (vibeMessagesResponse.messages) {
          if (markReadOnRetrieval) {
            const unreadMessageIds = vibeMessagesResponse.messages.filter(msg => msg.readStatus === 'UNREAD').map(msg => msg.messageId || '').filter(id => id !== '');
            if (unreadMessageIds.length > 0) {
              await this.markVibeAsRead(unreadMessageIds);
            }
          }
          return vibeMessagesResponse.messages;
        }
      // Mock delay to simulate network request
      return [];
    } catch (error) {
      console.error('Error fetching vibes:', error);
      return [];
    }
  }

  static async markVibeAsRead(messageIds: string[]): Promise<boolean> {
    if(!this.sessionToken || !this.currentUserId) {
      return false;
    }
    try {
      const readMessagesRequest: InboxReadMessagesByIdsRequest = {
        userId: this.currentUserId || '',
        token: this.sessionToken || '',
        body: {
          messageIds: messageIds,
          readStatus: 'READ',
        }
      }
      this.inboxApi.inboxReadMessagesByIds(readMessagesRequest)
      return true;
    } catch (error) {
      console.error('Error marking vibes as read:', error);
      return false;
    }
  }

      return false;
    }

        token: this.sessionToken || '',

          category: 'user',

          subject: 'Good Vibes',
        }
      }
      const sendUserMessageResponse: InboxSendMessageResponse = await this.inboxApi.inboxSendInboxUserMessage(sendVibeRequest)

      }
      return false;
    } catch (error) {
      console.error('Error sending vibe:', error);
      return false;
    }
  }

  static async getVibeCount(): Promise<VibeCount> {
    if(!this.sessionToken || !this.currentUserId) {
      return 0;
    }
    try {
      const currentVibeCountRequest: TrackablesGetEnergyRequest = {
        name: ['good_vibes'],
        token: this.sessionToken || '',
      }
      const currentVibeCountResponse = await this.trackablesApi.trackablesGetEnergy(currentVibeCountRequest)
      let energy = currentVibeCountResponse.settings && currentVibeCountResponse.settings.length > 0 && currentVibeCountResponse.settings[0].defaultEnergy ? currentVibeCountResponse.settings[0].defaultEnergy : 0;
      return energy;
    } catch (error) {
      console.error('Error fetching vibe count:', error);
      return 0;
    }
  }

  static async consumeVibe(delta: number = 1): Promise<VibeCount> {
    if(!this.sessionToken || !this.currentUserId) {
      return 0;
    }
    try {
      const consumeVibeCountRequest: TrackablesConsumeUserEnergyRequest = {
        userId: this.currentUserId || '',
        energyName: 'good_vibes',
        token: this.sessionToken || '',
        body: {
          delta: delta,
        }
      }
      const consumeVibeCountResponse = await this.trackablesApi.trackablesConsumeUserEnergy(consumeVibeCountRequest)
      const newEnergy = consumeVibeCountResponse.energy ? consumeVibeCountResponse.energy : 0;
      return newEnergy;
    } catch (error) {
      console.error('Error consuming vibe:', error);
      return 0;
    }
  }

  static async searchUser(searchString: string): Promise<Profile[]> {
    if(!this.sessionToken || !this.currentUserId) {
      return [];
    }
    try {
      const searchProfilesRequest: ProfilesSearchProfilesOperationRequest = {
        token: this.sessionToken || '',
        body: {
          limit: 50,
          offset: 0,
          searchFields: [
            {
              key: 'first_name',
              operator: 'CONTAINS',
              value: searchString
            }
          ],
        }
      }
      const searchUserResponse: ProfilesSearchProfilesResponse = await this.profilesApi.profilesSearchProfiles(searchProfilesRequest)
      if (searchUserResponse.profiles) {
        const profileIds: string[] = Object.keys(searchUserResponse.profiles);
        const profiles: Profile[] = profileIds.filter(id => id !== this.currentUserId).map(id => {
          const profileData = searchUserResponse.profiles ? searchUserResponse.profiles[id] : null;
          return {
            id: id,
            profile_pic: (profileData && 'profile_pic' in profileData ? profileData.profile_pic as string : ''),
            first_name: (profileData && 'first_name' in profileData ? profileData.first_name as string : ''),
            last_name: (profileData && 'last_name' in profileData ? profileData.last_name as string : '')
          };
        });
        return profiles;
      }
      return [];
    } catch (error) {
      console.error('Error searching users:', error);
      return [];
    }
  }

  static async sendFriendRequest(targetUserId: string): Promise<boolean> {
    if(!this.sessionToken || !this.currentUserId) {
      return false;
    }
    try {
      const userProfileRequest: ProfilesGetProfileRequest = {
        userId: this.currentUserId || '',
        token: this.sessionToken || '',
      }
      const getUserProfileRequest: ProfilesGetProfileResponse = await this.profilesApi.profilesGetProfile(userProfileRequest)
      if(!getUserProfileRequest || !getUserProfileRequest.profile) {
        throw new Error("User profile not found");
      }
      const sendFriendRequestRequest: SocialGraphSendFriendRequestRequest = {
        userId: this.currentUserId || '',
        token: this.sessionToken || '',
        body: {
          targetUserId: targetUserId,
          metadata: getUserProfileRequest.profile || {},
        }
      }
      const sendFriendRequestResponse = await this.socialGraphApi.socialGraphSendFriendRequest(sendFriendRequestRequest)
      if(sendFriendRequestResponse) {
        return true;
      }
      return false;
    } catch (error) {
      console.error('Error sending friend request:', error);
      return false;
    }
  }

  static async acceptFriendRequest(friendRequest: FriendRequest): Promise<boolean> {
      if (!this.sessionToken || !this.currentUserId) return false;

      // Fetch *your* profile to store on your edge
      const meReq: ProfilesGetProfileRequest = {
        userId: this.currentUserId || '',
        token: this.sessionToken || '',
      };
      const meRes = await this.profilesApi.profilesGetProfile(meReq);
      const myProfile = meRes.profile || {};

      const addFriendRequest: SocialGraphAddFriendRequest = {
        userId: this.currentUserId || '',
        token: this.sessionToken || '',
        body: {
          targetUserId: friendRequest.id || '',
          metadata: myProfile,
        },
      };
      await this.socialGraphApi.socialGraphAddFriend(addFriendRequest);
      return true;
    }
