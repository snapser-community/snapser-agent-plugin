# Bring your own

Snapser enables developers to integrate their own custom services and/or when applicable even game servers , or connect external game servers through a custom gateway load balancer.
{/* For developers that prefer to use their own data stores instead of relying on the Snapser data plane, Snapser also offers the flexibility to attach their preferred data plane during Snapend creation. */}


* [Bring Your Own Snap](/docs/custom/bring-your-own-snap) - Snapser provides developers to deploy microservices, macroservices, or monoliths, allowing multiple services in any language, with Snapser CLI facilitating building, pushing to a personal Snapser Container Registry, and deploying new versions to Snapend.
* [Bring Your Own Workstation](/docs/custom/bring-your-own-ws) - Bring your own workstation is a way for developers to attach their workstation to their Snapend. Thus, effectively allowing them to run their code locally and debug it.
* [Bring Your Own Game Server](/docs/custom/bring-your-own-server) - Snapser provides developers to deploy headless game servers in any language, with Snapser CLI facilitating building, pushing to a personal Snapser Container Registry, and deploying new versions of the Game server that can be used with the Snapser fleet.
* [Bring Your Own External Server](/docs/custom/bring-your-own-external-server) - Developers can integrate existing cloud functions or servers behind their Snapend gateway, utilizing gateway authentication and authorization, with only a server name and HTTPS forwarding domain needed for security compliance.
{/* * [Bring your Own Data Stores](/docs/custom/bring-your-own-data-store) - Snapser prioritizes our customer's data ownership, allowing efficient ML pipeline management and comprehensive visibility; developers can attach their data plane during Snapend creation, storing user data on it. */}
