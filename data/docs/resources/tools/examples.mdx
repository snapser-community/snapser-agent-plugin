Snapser provides examples of Snapends, BYOSnaps, and Game Servers to help you get started with your app development. Since the Snapser team has a games background, most of these examples are game specific.  However, they are still designed to be easy to use and can be customized to fit your specific needs, even if your application is not a game but may require similar backend services.

## Snapend Examples

Snapser currently provides pre-configured Snapends for the following categories / game types:
1. **Secure Cloud Storage**: Get plug-and-play scalable cloud storage to store any app data. Easily save and sync user data across devices with built-in security.
2. **Offline Single Player**: For games like Monument Valley, Alto’s Odyssey, or Limbo. These templates are tailored for solo experiences that prioritize story, puzzles, or casual offline play—with support for local saves, progression, and smooth startup without server calls.
3. **Arcade Social**: Inspired by Candy Crush, Subway Surfers, or Temple Run. These templates are built for casual games with viral loops—supporting leaderboards, lives/energy systems, gifting, and lightweight social features.
4. **Party Multiplayer**: For games like Among Us, Fall Guys, or Stumble Guys. These templates help you spin up drop-in/drop-out multiplayer with lobbies, player sessions, and social chaos—perfect for party games focused on quick fun and group dynamics.
5. **Competitive Multiplayer**: Modeled after Clash Royale, Brawl Stars, or Hearthstone. These templates power real-time PvP, matchmaking, ELO-based ranking, and season resets—great for building games where every second counts and every match matters.
6. **Live Service RPG**: Inspired by Genshin Impact, Diablo Immortal, or AFK Arena. These templates are ideal for RPGs with evolving content, gacha, dailies, inventory management, and live ops tooling—built to scale with your world.
7. **Battle Royale**: For games like Fortnite, PUBG Mobile, or Call of Duty: Warzone Mobile. These templates support large-scale lobbies, player drops, shrinking zones, and real-time combat sync—your foundation for high-stakes, last-one-standing showdowns.
8. **Hosting Stack**: Spin up scalable game servers with matchmaking, regions, and live monitoring out of the box. These templates power your multiplayer or real-time experiences effortlessly.
9. **User Engagement**: Engage your users with built-in chat, inbox messages, push notifications, and emails. These templates help you connect with users inside and outside the app.
10. **Auth**: Kickstart secure user logins in minutes. These templates support anonymous login, email OTP, or OAuth flows—so your users can jump in fast and stay connected.


### Usage
You can leverage these examples in three different ways:

#### 1. Download the example manifest
When you visit the **Community > Resources** page, you see a tab called **Snapend Examples**. Each example, has a set of recommended Snaps as well as a button called **Manifest**. This button allows you to download the manifest for the Snapend. The manifest is a JSON file that contains all the information about the Snapend, including the Snaps, their configurations, and the network setup. You can use this manifest to create a new Snapend with the same configuration, using the **Import** tool in the **Add Snapend** wizard.

![Snapend Examples](/images/docs/resources-snapend-examples.png)


#### 2. When creating an app
When you go to create an App, the widget allows you to select a example Snapend to spin as well.

![Quick Add](/images/docs/quick-add-game.png)

#### 3. When creating a Snapend
When you go to create a new Snapend, you will see a button called **Quick Add**. This button allows you to select a example Snapend to spin up. The example Snapend will be created with the recommended Snaps and their configurations.

![Quick Add Snapend](/images/docs/quick-add-snapend.png)

## BYOSnap Examples
Snapser provides a set of BYOSnap examples to help you get started with your app development. These examples are designed to be easy to use and are good starting points for your own BYOSnaps.

Presently, we have the following BYOSnap examples:
1. **Basic Examples**: Basic examples of BYOSnaps written in C#, Go, Python, and Node Typescript. These examples are designed to be easy to use and can be customized to fit your specific needs.
2. **Intermediate Examples**: Intermediate examples of BYOSnaps written in C#, Go, Python, and Node Typescript. These examples show how to integrate your BYOSnap with the internal SDK and local debugging.
3. **Advanced Examples**: Advanced examples of BYOSnaps written in Python. These examples show how to tap into the Snapser Hooks system from your BYOSnap.
4. **Realtime Events**: BYOSnap example showing how you can register custom events, listen for them in code and emit them.

![Snapend Examples](/images/docs/resources-byosnap-examples.png)

## Game Server Examples
Snapser provides a set of Game Server examples to help you get started with your game development. These examples are designed to be easy to use and are good starting points for your own Game Servers.

Presently, we have the following Game Server examples:
1. **Basic Examples**: Basic examples of an open source game Super Tux Racer running on Snapser fleets.
2. **Intermediate Examples**: Intermediate examples of Game Servers written in C++, Go and Unity.
