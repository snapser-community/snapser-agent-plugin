# Platform Tools

With a powerful Web portal, CLI, a range of user friendly tools and an ever expanding Snaps Marketplace, Snapser provides all the resources you need to build and manage your game or app.

## Snapser Portal

The **Snapser Portal** streamlines account management, including onboarding and role assignment. Teams and Invites enable efficient access management with specialized roles like Business, Design, and Engineering, while Roles offer precise access control across company, app, cluster, cluster-service, and cluster-service-user levels.

* [Portal Overview](resources/portal) - Web application facilitating Snapser account management, offering onboarding, role assignment, and organized views for apps and Snapends.
* [Studio Functions](resources/portal/team) - Enables efficient access management within game studios, assigning specialized roles like Business, Design, and Engineering. Users can have multiple roles and be invited to different levels—company, app, or Snapend.
* [Roles](resources/portal/access) - Enables precise access control for app developers, offering tailored roles across five main categories: company, game, cluster, cluster-service, and cluster-service-user.
* [Audit](/docs/resources/tools/audit) - Offers a comprehensive audit trail of all actions performed on Snapser, ensuring transparency and accountability.
* [Alert Manager](/docs/resources/tools/alert-manager) - Configure notification channels (Slack, PagerDuty, email) and subscriptions for the platform alerts that fire across your Snapends.
* [Snaps](/docs/resources/marketplace) - Provides a range of backend services game/app development, including analytics, authentication, leaderboards, and more.
* [Examples](/docs/resources/tools/examples) - Provides a range of game templates, BYOSnap and Game Server examples for game studios to kickstart their development process.


## Snapser CLI

**[Snapctl](resources/cli)** is Snapser's CLI tool streamlines integration into developer pipelines. The tool facilitates Bring Your Own Snap (BYOS) and Bring Your Own Game Server (BYOG) tasks such as creating, publishing images, and version updates.
