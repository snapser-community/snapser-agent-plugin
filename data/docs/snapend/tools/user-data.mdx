# User Data Tool

## Concept
During app development often times you want to have easy access to all the
data for a particular user. This may be your own user during development or a
live users who is complaining about a bug. The Snapser User Data tool gives
you a single glass pane to see all the data for a particular user.

## Tool Location

You can find the User Data tool under the Quick links of the home page of
your cluster. You can also find it under Tools from the left Nav once you go
to your Cluster home page.

![snapser-user-data-id](/images/docs/user-data-id.png)

## Details

Once you go to the User Data tool, you will see a text box to enter a user
Id. Once you enter a user Id, you will see a list of all Snaps in the cluster.
Clicking on each Snap will show you the data stored in the Snap for that user.
As an example: Say you are using the Auth, Storage and Leaderboard Snaps in
your game. In the User Data tool you will be able to see all of the users
sessions, their blob data in storage and their leaderboard scores.

![snapser-user-data-view](/images/docs/user-data-view.png)
