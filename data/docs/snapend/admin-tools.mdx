# Snaps Configuration

Snap Configuration tools are a way you can take your custom backend and configure it for your app. Every Snap in the Snapser Marketplace comes with its own set of configuration tools.

For example: Say you have the Inventory Snap snapped to your Snapend. The Inventory Snap comes with an admin tools for setting up your main inventory, adding virtual currencies, setting up currency exchange rates, etc

<Note>
 If there's a specific configuration tool you feel is missing, please don't hesitate to contact our support team.
</Note>

## Location

Once you are on your Snapend view, you will see a tool called **Snaps Configuration** under **Quick Links**. Clicking on it will open the Admin tool view. There will be a select dropdown in the top left, allowing you to quickly toggle between admin tools of different snaps.

![Snapend Pic](/images/docs/my-snapend.png)

## Audit
Every action that you take in the configuration tools is audited. This allows you to track who made what changes to
your Snapend.

![Snapend Pic](/images/docs/snapend-audit.png)

<Warning>
  Only Premium tier customers have access to the Audit feature.
</Warning>

## BYOSnap Configuration Tools
